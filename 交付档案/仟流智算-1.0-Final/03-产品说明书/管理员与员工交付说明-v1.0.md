# 管理员与员工交付说明

## 管理员交付

- 先创建资源，再建模型／Route／规则，最后创建主体和发 Key。
- 每位员工默认一把主体 Key；完整 Key 只在生成或重置后可复制一次。
- 模型授权、厂商池额度和 Key 白名单由“接入配置”统一维护；不要再走历史直写端点。
- 生产报障先查 request ID、资源健康、额度窗口和熔断事件，不要求员工提交对话正文。
- 停用、归档、重置 Key、停 Route 或资源会影响真实调用，操作前确认影响范围。

## 员工交付

- Base URL：`https://gw.qianliuai.com/v1`。
- API Key：管理员提供的 `sk-qianliu-*`，禁止提交 Git、发群或放截图。
- 模型：只使用 `/v1/models` 返回的 `ql-*` 名称。
- 失败时记录时间、模型、状态码和 request ID；不要连续高频重试。
- WorkBuddy、ZCode 等客户端若自动追加 `/v1`，基础地址需按客户端规则避免形成 `/v1/v1`。

详细功能、边界和异常说明见 [产品说明书](./仟流智算1.0-产品说明书-v1.0.md)。
