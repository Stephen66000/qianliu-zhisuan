Gateway 执行层

北向协议

Models、OpenAI Chat、Anthropic Messages。

鉴权

主体识别、授权、额度与并发门禁。

候选与评分

硬过滤、多因子评分、稳定 tie-break。

Affinity

显式 Session ID 的 HMAC，健康时复用。

故障边界

提交前可切换，提交后禁止跨上游拼接。

逐 Attempt 计量

真实消耗不可覆盖，请求只形成一个结算汇总。

三、端到端经营闭环

登记真实资源
创建员工／项目主体
分配 Key、模型与额度
Gateway 调度并调用
逐 Attempt 计量结算
告警、调整与自然月复盘

四、核心产品对象关系

Enterprise拥有管理员、员工、项目、资源、路由和账本。
Principal员工或项目；持有 Key、模型授权、额度和并发。
Provider Resource某厂商的一份 API 或 Coding Plan 真实供给。
Unified Model / Route把客户端模型名映射到有序候选资源。
Request一次下游调用的唯一请求身份与结算边界。
Attempt每次真实上游尝试；有消耗就形成独立账本明细。
Settlement同一 Request 的唯一汇总，不覆盖 Attempt 事实。
Policy Version冻结额度、价格、评分、峰谷和调度规则。
权威边界：产品范围以 PRD v0.3 为准；技术实现以 TRD v0.3 与 ADR 为准；本图负责产品结构和责任关系。
