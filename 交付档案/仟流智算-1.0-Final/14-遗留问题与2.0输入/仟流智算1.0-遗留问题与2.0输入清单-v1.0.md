## 3. 不自动进入 2.0 的项目

- 对话正文默认留存；
- 自动采购或不可逆自动调度；
- 为了“看起来完整”而实现没有真实客户端需求的协议；
- 仅为降低文件行数而进行高风险重构。

上述能力若要进入 2.0，必须由 PRD 重新说明用户价值、风险、验收和数据边界。
