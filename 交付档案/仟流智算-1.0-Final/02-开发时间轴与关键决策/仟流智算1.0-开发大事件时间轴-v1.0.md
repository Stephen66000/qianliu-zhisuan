## 关键决策与返工模式

1. **正文零留存保持为硬边界**：诊断能力通过 metadata、request ID、Attempt 和 canary 完成，不靠保存会话正文。
2. **协议能力显式启用／拒绝**：一期稳定支持 Models、OpenAI Chat、Anthropic Messages；未启用能力不做静默降级。
3. **仟流 IDE 移出一期签字范围**：第三方客户端可先完成真实使用；不以客户端缺口阻塞 Gateway 和生产工程，但必须如实记录。
4. **账本不可由前端重算**：Token、费用、倍率、Attempt 和结算由后端事实模型提供，页面只展示与下钻。
5. **生产问题驱动多轮候选重开**：每次热修、迁移或语义变化都形成新候选并补审，导致旧 `v1.0.0` 标签失效。
6. **生产验收不污染正式数据**：POOL-040／041 使用当前生产镜像配隔离 PostgreSQL／Stub 上游做确定性验收。

## 时间口径

本时间轴基于 Git 主线提交时间、Planning Change、Handoff、Final-Audit 和 Production-Release Evidence。它记录阶段性大事件，不以提交数量冒充进度；详细逐提交记录由 Git 保留。
