## WT-01 ~ WT-09 走查路径对照

| 走查 | 原型路径 |
| --- | --- |
| WT-01 登记 DeepSeek API、智谱套餐、Kimi 套餐 | 厂商资源 → 「+ 登记资源账号」弹窗（厂商/模式/账号名/模型/费用/额度/周期/上游凭证/规则模板） |
| WT-02 创建员工、取得 Key、分配模型和额度 | 使用主体 → 「+ 新建员工」四步：创建账号 → 生成 Key（明文仅一次） → 分配模型与额度（可套模板） → 接入信息 |
| WT-03 员工按接入信息完成首次调用 | 四步弹窗末屏：Gateway 地址 + Key + WorkBuddy/ZCode/Claude Code 配置块一键复制；仟流 IDE 免配置说明 |
| WT-04 创建项目并同样分配资源 | 使用主体 → 「+ 新建项目」（复用同一四步流程，无登录账号说明） |
| WT-05 查看某员工 Token、实际扣减、API 费用 | 用量账本 → 筛选主体 → 「明细」弹窗：计量三段式（输入／输出／缓存 Token → 实际扣减+规则版本 → 实际费用/套餐内） |
| WT-06 额度耗尽停止；允许超额后恢复并产生超额记录 | 场景切「额度耗尽」：账本出现「拒绝·主体额度耗尽」；使用主体 → 王一帆详情 → 开启「允许超额」；首页超额名单按超出比例排序 |
| WT-07 套餐失效切同池账号；套餐转 API 仅开关开启时 | 场景切「资源不可用」：智谱主账号 401 → 已切备用账号提示；厂商资源「API 兜底」开关（默认关闭，开启需确认，费用单列说明） |
| WT-08 首页发现资源不可用/主体异常并进入明细 | 场景切「资源不可用」或「额度耗尽」：首页未处理异常/超额名单 → 「处理」进入异常告警/使用主体明细 |
| WT-09 停用员工或重置 Key，旧 Key 立即不可用 | 使用主体 → 行内「停用」（确认弹窗说明 Key 立即失效、历史保留）；详情 → Key「重置」（警告旧 Key 5 秒内全局失效） |

## 视觉规范落点

- 语义令牌（canvas/surface/border/text/action/success/warning/danger），无散落硬编码；浅色主题（Beta 首轮按规范先验浅色）。
- 仪表盘草案 0.1：Zone 区域容器（首页 4 个）；核心区「本月核心指标」三件套（深一档边框 + 轻阴影 + 20px 内边距）；颜色只给状态（常态状态灰标签，橙/红仅给需处理信号）；字号三级收敛（内容 15/600 > 说明 13 > 元信息 12，统计数字 24px）；结构堆叠条表达调用构成；断点只降列与折叠（1280/1024/860）。
- 仟流青 #00D2D4 全原型仅用于品牌标一处点睛，符合每视口 1-2 处上限；正文最小 12px 仅元信息，功能文字 ≥13px。
- 侧栏 256px、顶栏 64px；「已完成/已验证」绿色仅用于真实验证语境（内容零留存校验、步骤完成）。

## 已知原型边界（非实现承诺）

- 数据为内置模拟数据，操作仅前端即时反馈，不持久化；
- 「原型场景」开关是走查辅助装置，非产品功能；
- Gateway 地址、Key 均为示例占位；
- 深色主题未出（Web 规范：首轮先验浅色，进入实现前由 Stage Plan 冻结）。
