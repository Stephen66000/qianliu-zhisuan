### 双路复审／V1.4 主审 Finding 整改结果

- 采购复盘改为直接串联经营账单余额桥接结果；账本 API 计价只作为核对证据。采购现金、API 花费和套餐费用均由后端按币种返回，前端不再 `Number/reduce`；套餐综合利用率复用经营账单成本加权结果。
- Dashboard、UsageOverview、明细筛选及 usage aggregate 全部改按 `ledger_transaction.created_at` 结算时间归属；0054 清除旧请求时间聚合缓存并按结算时间重建 dirty 桶，回退时按旧语义重建且存在 `MIXED` 事实时 fail-closed。
- 缓存／推理缺字段不再标记为全部厂商上报；缺字段为 `MIXED`，显式 0 与非法非负安全整数分别验证。首页与下钻共同解释 `NO_DATA／PROVIDER_REPORTED／ESTIMATED／ACCOUNT_AGGREGATED／MIXED／UNKNOWN`。
- 上月期末仅在同资源、同币种时自动承接，且优先于人工事实和月初快照；异币种时回退有效月初快照／人工事实。经营账期匹配固定北京时间，不再读取企业可配时区。
- 期初、充值、期末、API 花费、套餐费用和总花费均保留按币种明细；仅不可合计的标量 fail-closed。CNY、USD、多币种及“无余额但有充值”反例均覆盖。
- 缺订阅开始或结束时，资源利用、采购复盘、经营账单套餐分析、闲置金额与成本加权汇总共同 fail-closed；5 小时／周窗口只作独立事实。
- 多 API 资源连续补录会在真实 rerender 后同步剩余资源与币种；第二笔请求目标由测试锁定。
- 补录 API 年份与 `numeric(24,8)` 边界统一为 4xx；财务事实与 operation_log 同事务，审计失败整体回滚、重试可恢复。0053 增加操作人企业复合外键，并实测跨租户 actor、UPDATE／DELETE 不可变触发器。
- 缺口 code／field／reason 分别覆盖期初、期末、币种和负桥接，不再统一误指 `ending_balance`。
