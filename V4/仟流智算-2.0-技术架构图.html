三条数据链

新页面只建立读模型，不发明第二套事实。

请求与计量链（1.0）

  • 请求 → Attempt／Usage → Ledger／Settlement
  • 首页、用量账本和经营账单共同回算
  • 2.0 不改 Gateway 的鉴权、路由和扣减语义

组织与经营链（2.0）

  • 通讯录／Excel → 映射 → 主体与组织关系
  • 结算事实 + 归属快照 → 部门成本与预算状态
  • 日／周／月只改变查询窗口，不改变底层事实

资源与复盘链（2.0）

  • 厂商原生权益 + 使用事实 → 利用率与耗尽事实
  • 无法计算时记录原因，不伪造统一 Token
  • 采购复盘只给事实与备注，不自动代替人决策
