# 额度规则与计价链路修复：实施及验收

日期：2026-09-05

实施分支：`codex/quota-pricing-review-20260905`；基线 `b637f52931bd1046787a6d335f486151b9870cac`。

状态：本地代码实施、目标回归、浏览器验收与 I1 有界审核完成；Mac Mini 生产预检、部署及真实高峰样本尚待用户操作。

## 已实现

- 两个 Tab：计价、调度策略。新建规则从已同步模型和具体资源开始，配置优先级、权重、价格后一次保存启用。旧模型和路由生命周期收在“已有模型与路由管理”，常规新建入口已移除；部门预算入口已移除。
- 同厂商、同模式价格沿用，复制当前有效的完整基础/窗口配置；未来版本不混入，目标及版本重新设置。允许核对、编辑、移除规则集中的各项；保存前明确确认是否替换该资源该模型整套旧价格。
- `POST /pricing-configurations` 以事务提交规则集、模型/路由启用、审计和幂等回执。校验企业、资源状态、验证记录、版本、复制来源、价格模式和重叠窗口。
- API 价格版本增加 `pricing_mode`。旧版本默认 `ABSOLUTE`，继续按绝对单价计算；新 `MULTIPLIER` 版本将三项基础单价、倍率和时段一同冻结在同一条规则版本内。因此基础规则 ID 与窗口规则 ID 可以相同，不依赖结算后的可变规则关联。
- 每次上游调用前冻结价格时点，API 完成分项 Decimal 乘加后乘倍率，再一次舍入入账；套餐继续使用原扣减语义。
- 初次调度的倍率与反事实基础价格来自同一冻结规则；每个上游 Attempt 复核实际资源的当前策略，零消费重选受尝试次数上限约束，保存 `dispatch_check` 证据。
- `ledger_line` 记录价格模式、基准规则、命中窗口、有效倍率、适用时刻、计算结果及质量；经营账单继续归集数据库事实。
- 策略增加独立存档，限制 RETIRED 状态、企业和版本；查看存档保留恢复/复制为新版本能力。策略发布在事务内复核当前版本和计价就绪状态。

## 数据迁移

新增 `0064_quota_pricing_and_policy_archive`：

| 表 | 增量 |
| --- | --- |
| billing_rule | pricing_mode，旧行默认 ABSOLUTE；MULTIPLIER 要求 API_PRICE、正倍率及三项基础单价 |
| dispatch_policy | archived_at、archived_by_admin_id、version；仅 RETIRED 允许存档 |
| upstream_attempt | dispatch_check JSON，保存调用前复核证据 |

没有新账本表、截图导入表，也没有厂商资金、历史 Token 或历史结算结果回填。价格新版本替换只修改旧规则的生效截止时间，历史账本快照保持原值。

已经创建新倍率规则时，旧应用无法正确解释其费用；不可直接退回旧 Gateway。发布失败的脚本先停写，查询确认无新倍率事实后才恢复旧镜像；查询失败或结果不确定均保持停止。脚本不执行数据库 down 或备份覆盖恢复。

Gateway 数据库场景实测：输入 1,000,000、缓存命中 200,000、输出 100,000；命中/未命中/输出单价分别为 1/2/4 元每百万 Token，3 倍计价得到 `6.60000000` 元。倍率条件从真实规则解析，可直接阻止上游调用。追加场景证明调度开始后才出现 SWITCH/REJECT 时仍会重选/拒绝，且原候选零费用留证。

浏览器流程从 PENDING_CONFIG 模型开始，选择资源并填写价格，保存后数据库路由 enabled=true、priority=80、weight=2；之后创建策略、校验、发布、停用、存档，默认列表隐藏，查看存档可见。截图保存在同目录的 `pricing-form.png` 和 `policy-archive.png`。

复现命令：

```sh
corepack pnpm@11.11.0 exec tsx scripts/run-quota-pricing-e2e.ts
```

浏览器脚本使用本机已安装 Chrome；可用 E2E_BROWSER_CHANNEL 选择其他已安装通道。首次环境检查修正了测试 KEK 的 Base64 编码和本机浏览器路径，未新增系统安装。

## I1 审核

独立审核任务：`quota_i1`。仅执行 I1，不执行 I2/IR2。

首轮发现并修复：调用前新 SWITCH 的重选、旧创建/启用入口模式绕过、不同生效时间规则复制遗漏、策略草稿并发校验、反事实价格在途重读、未来价格状态。复核又修正初次调度倍率与基线两次读取的竞态；调度现在直接使用冻结基线的倍率。
