# 第四版原型：卡片单行与大 Token 数字

2026-09-06。本轮只修改讨论原型，未修改正式统计接口或部署。

- 卡片标题和数值各保持单行；按实际可用宽度测量并缩小字号，不使用省略号遮掉数字。
- 达到 100,000,000 Token 时，顶部 Token 卡片改用“万”，最多保留两位小数；小于阈值继续显示完整整数。
- 20 亿显示 `200,000 万`，200 亿显示 `2,000,000 万`。单位与数值在同一行。
- 换算只是展示处理。Token 总量、YTD、人均及环比的计算保持原值；明细表保留完整数字，卡片的辅助阅读标签也保留原始数值。
- 在渲染、月份／厂商／页签切换、字体加载及容器宽度变化后重新适配字号。
- 桌面五个指标仍为一行；窄屏按屏幕宽度响应排列，不因数值增大临时改变卡片列数。

浏览器验证记录见 prototype-validation-v4.json：检查 320—1440px 的卡片内容无溢出、字体不低于 11px，以及 1 亿前后、20 亿、200 亿、2 万亿等数值的显示和适配。原型截图为 prototype-trends-v4.png。
