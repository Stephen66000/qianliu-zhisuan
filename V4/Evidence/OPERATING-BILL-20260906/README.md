## 数据来源核查结论

核查的是当前代码数据链，未连接生产数据库复算截图中的 109.3 元。

1. `OperatingBillOverview.tsx` 读取 API 返回的 apiCost / packageCost，不硬编码金额。
2. `operating-bill-repository.ts` 的 buildDraft 在厂商资金账启用时应用 `projectOperatingBillFinance`。
3. `provider-finance-repository.ts` 汇总 `ledger_line` 中 API / PRICED_USAGE 的 api_cost，并计入 `provider_finance_event` 中历史费用调整。`operating-bill-finance-projection.ts` 将结果写入总览和厂商行。
4. 套餐月费用目前取 monthlyPlanCashCny：按流水发生月份汇总套餐购买、续费、冲销的 cash_paid_cny。这是“付款月”的现有规则，尚未改为跨月费用归属。年付／跨月订阅应另行确认，不按猜测修改。
5. 旧 CSV API 仍可以追加经营快照，但不会生成充值／套餐实付流水，无法作为新厂商资金账的金额导入入口，因此移除经营账单里的入口。旧解析器和后端接口保留，不删除历史。
6. 缓存实际参与计价。`packages/domain/src/billing-rule.ts` 的 computeApiCostFromRule：缓存命中输入按命中价计费，其余输入按未命中价计费，输出按输出价计费；Gateway 调用该函数。缓存是输入子集，不重复加入总 Token。
