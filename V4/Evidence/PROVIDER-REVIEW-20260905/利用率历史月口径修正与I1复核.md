## 需求纠正

首轮把“三个月均值”实现成必须具备三个完整历史月，导致资源已有完整 8 月数据时，9 月仍显示 `—`。需求方在生产页面验收时明确：

- 有 1 个完整历史月，使用该月作为分母；
- 有 2 个完整历史月，使用两个月均值；
- 有 3 个及以上，滚动使用最近三个完整月均值；
- 资源登记所在的非完整月份及其 Token 不进入分母；
- 只有没有完整历史月，或可用完整月总量为 0 时显示 `—`。

因此当前三条生产资源创建于 2026-07-29，2026-08 是完整历史月；选择 2026-09 时应以 8 月真实 Token 为分母并显示利用率。
