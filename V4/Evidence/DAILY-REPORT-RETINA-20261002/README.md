# 日报真实 2× 栅格化修复（2026-10-02）

日报模板的 SVG 视口为 540×760。旧渲染器按此尺寸解码为位图，然后用 drawImage 放大到 1080×1520，文字细节无法恢复；Logo 单独绘制，因此出现 Logo 清晰而文字模糊。新的共享渲染器在 SVG 解码前设置目标视口尺寸，保留逻辑 viewBox，解码后按 1:1 绘制。无 viewBox 的输入补充原始坐标边界，裁切 viewBox 的偏移与 Logo 共用同一换算。

## 授权与范围

用户确认“先修真实 2× 图片 → 保留字体和 Logo → 补清晰度验证 → 本地与 Linux Worker 验证后部署 Worker”。本次修改渲染器与必要的坐标处理，不改变日报数据、字体字号、颜色或发送方式；验证用合成数据，不调用完整日报任务，不向企业微信重发消息。

## 验证证据

- 49/49：日报、周报、激励模板、中文、PNG、报表逻辑、企业微信客户端 mock 与 8 项新的像素/坐标回归。
- Worker typecheck、lint、build 退出码均为 0。
- 新回归检查 Image.decode 的实际尺寸为 1080×1520，能够识别旧的“540 位图放大”实现；检查带非零原点的 viewBox 中 PNG Logo 与矢量色块的像素位置一致，以及缺少 viewBox 时的缩放。
- 合成日报输出 1080×1520，与手动设置 1080 SVG 视口得到的高清参考逐字节一致。复现脚本 render-sample.mjs 可在 Linux 镜像内执行，只导入模板和渲染器，不启动 Worker 调度器。
