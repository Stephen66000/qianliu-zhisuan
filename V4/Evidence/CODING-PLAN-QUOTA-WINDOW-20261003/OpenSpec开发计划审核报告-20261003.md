## 2. P1 阻断项

### F1 — 缺少可跨查询与周期保存的当前耗尽事实

- **计划位置**：§4.5、§5“默认不新增迁移”、A10。
- **代码证据**：`packages/database/src/provider-quota-window-types.ts:25-48` 没有凭证／故障绑定；`provider-quota-window-repository.ts:64-109` 每个窗口归档旧行再插入当前行，UNSUPPORTED 也更新 last_success_at；Worker `runner.ts:157-177` 只依据当次响应恢复。
- **触发**：智谱周剩余为 0 → 后续只返回有余量的 5 小时窗口 → 周窗口被记为 UNSUPPORTED。现有恢复条件不记得先前周阻断；反过来无限追查旧零值又可能永远不恢复。
- **影响**：A10 无法仅凭“优先复用历史”确定实现；凭证轮换与新周期也无法可靠隔离。
- **关闭要求**：冻结耗尽事实、credential generation、故障／周期边界、置位及清除证据。明确选择现有结构或最小字段迁移并证明能满足场景，不把存储决定推迟到开发中。

### F2 — 到达时间会提前放行生成探针，与确认余量合同冲突

- **计划位置**：§4.1—4.4、A8。
- **代码证据**：Gateway `runtime-controls.ts:101` 将 WINDOW_EXHAUSTED 映射为 UPSTREAM_RATE_LIMITED；域 `resource-lifecycle.ts:306-321` 在 cooldown 到期返回 admit=true/probe=true；`runtime-assurance-events.ts:172-177` 只凭 recover_at 关闭事件。Worker `main.ts:315-318` 的事件恢复发生在额度查询之前。
- **复现**：纯函数合成测试先创建 RATE_LIMITED，时钟到 cooldown 后，quotaSyncConfirmed=false 时 evaluateAdmission 仍返回 `{admit:true,probe:true}`。未访问厂商、未修改业务代码。
- **影响**：即使 Worker 下一次查询失败或周额度仍为零，也可能先发出消耗生成额度的探针；只改提示或 Worker 查询不能关闭这一入口。
- **关闭要求**：明确窗口耗尽与普通频率限流的准入方案、适用额度事件到期策略；覆盖 Worker 尚未完成查询的并发请求，不扩大改变普通限流合同。

### F3 — 禁止付费回退没有覆盖新请求的初始候选选择

- **计划位置**：§1 付费限制、WP2、A13。
- **代码证据**：`pipeline-attempt-execution.ts:107-111` 的停止位于已有 Attempt 之后；`pipeline-admission.ts:179-195` 过滤不能服务的 CP 资源后将剩余资源列为 eligible；`pipeline-attempts.ts:14-22` 在剩余候选中挑选初始 winner。该路径没有针对本能力的独立付费许可检查。
- **触发**：同模型配置 CP 与 API；CP 已耗尽，新请求尚未调用 CP 就只剩 API 候选。只在耗尽响应后 BREAK 无法覆盖这类初始路由。
- **影响**：潜在自动付费路径违反用户明确的额外付费授权约束。这里是源码路径推断，不是生产已发生扣费的结论。
- **关闭要求**：明确套餐请求意图、单独付费授权来源与范围，并覆盖准入、首次选路、显式 SWITCH 和重试。模型权限、已有余额及配置回退都不能自行充当用户付费授权。

### F4 — 行锁没有绑定查询结果的凭证与故障代次

- **计划位置**：§4.9、A12。
- **代码证据**：Worker `runner.ts:151-177` 在网络查询之后分别提交窗口并调用 recordQuotaSyncRecovery(resourceId)；仓储 `resource-pool-repository.ts:176-189` 仅重新锁行与检查当前状态，未接受查询凭证版本、故障标识或源窗口。两个窗口写入本身为独立事务。
- **触发**：旧凭证查询返回正余量后，另一操作轮换凭证或产生新的 EXHAUSTED，再执行旧结果恢复。当前状态若仍为可恢复类别，行锁无法识别结果已过时。
- **影响**：可能覆盖新故障；部分窗口可见性也可能让提示、资源、Key 集合与额度事件不一致。
- **关闭要求**：设计查询 token／预期凭证与故障版本、条件提交、锁顺序、窗口／资源／适用事件一致性和失败重试；用轮换及同状态新故障案例证明不会被旧结果解封。
