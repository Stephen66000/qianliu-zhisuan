## 4. 范围、迁移及风险

v1.1选定最小additive迁移：provider_resource两列、availability_event一列，不建新表平台。候选编号0087只表示设计，实际实施时要重新核对迁移头。本轮没有创建SQL/JS迁移文件，更没有运行迁移。

PLAN_ONLY会关闭混合CP/API模型的隐式付费回退，纯API模型不改；发布前列出影响。这是落实已确认不使用额外付费额度的方案，不暗示已改变任何平台扣费设置。

回滚旧镜像缺新门禁，先暂停本能力受保护模型并保留新增事实；不能直接重开旧流量并声称新的计费限制仍成立。旧未归属历史事件不能靠猜测归为额度，发布验收列出缺口；Kimi历史403不追查。

这些风险有明确任务与验收，不需要新增产品模块或额外治理平台。
