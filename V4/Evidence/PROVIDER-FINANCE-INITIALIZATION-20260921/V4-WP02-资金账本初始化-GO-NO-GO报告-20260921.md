### 分层合同（design §6）落实

1. 只读事务内**不写资金事件、不写订阅周期、不改 `ledger_line`、不写候选**——由 PostgreSQL `SET TRANSACTION READ ONLY` **强制**（任何写语句以 `25006` 失败），非调用方约定。
2. 候选元数据只在只读事务提交**之后**由独立控制事务保存；TTL 自该时刻起算，读取/失败/重放均不滑动续期。
3. 投影输入的 `usageRepairBaseline` / `usageRepairTargets` 是**入口回显通道**，预检固定传空数组，避免调用方伪造资格行；固定行集由投影按候选时点自行重算。
