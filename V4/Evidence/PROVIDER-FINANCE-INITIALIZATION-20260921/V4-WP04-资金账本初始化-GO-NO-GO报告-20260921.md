### 关键实现口径

1. **控制面不碰事务**：4.3 只做「会话企业确认 → 参数收窄 → 委派协调器 → 错误映射 → 审计」，`ProviderFinanceActivationCoordinator` 是唯一写入入口；`activation-state`/`activation-preview` 全部只读。
2. **静默门禁在 pipeline 之前短路**：Gateway 用 `chainGuards(maintenanceGate, authorizeModel)` 把 `createQuiescenceGate` 插到模型授权之前，命中有效租约直接 503 `enterprise_maintenance`（带 `retry-after`），**不进入 pipeline、不写 `ai_request`、不触达上游与账本**；`/v1/models` 不设门禁（管理员仍需看模型列表）。
3. **跨服务同一口径**：`provider-finance-quiescence.ts` 由 control-api / gateway / worker 共享，服务器时间语义统一（上限 60 分钟，窗口 CHECK 约束在库层 `expires_at <= started_at + 60min`）。
4. **公开面字段风格统一**：仓储返回 camelCase，HTTP 面为 snake_case，新增 `leaseView()` 在 3 个出口（启动/查询/解除）统一归一化，避免混用。
5. **零自动重试**：`ACTIVATION_RETRY_REQUIRED` 在 HTTP 层同样只映射为 409 + `retryable=true`，任何层不重试。
