## 二次修正（2.5.8，2026-09-19 16:20）：订阅兑底口径与按列降级

- **生产反馈**：2.5.7 部署后智谱行整行「数据不足」。生产 SQL 核查：智谱 9 月 Token 444,615,835 真实存在，但 9 月无付款流水（9 月仅 Kimi 续费 ¥199；智谱为订阅制，费用在订阅周期登记）。
- **根因**：①取数口径缺陷——订阅制套餐非每月付款，「当月付款净额」口径在无流水月份为 0；②实现缺陷——月费缺失时整行判缺失，把真实 Token 列也隐藏。
- **修复**：
  1. 月费口径：当月付款净额优先；当月无付款但存在覆盖当月的生效订阅（未冲销）时，取订阅固定费并在页面以「*」标注 + 脚注说明；
  2. 按列降级：Token 列与等效 API 成本仅需 Token 数据即可展示，价格相关单元格（摊薄单价/降本/折扣）独立判缺失；
  3. `subscriptionFeeForMonth` 导出可测：仅取覆盖当月（含部分覆盖）且未 REVERSED 的订阅，优先 ACTIVE。
- **验证**：web 476 全过（新增「月费缺失 Token 不连坐」「订阅兑底+标注」「subscriptionFeeForMonth 边界」3 用例）；typecheck / lint / build / 架构 / 体量 / audit 全绿；体量基线 527。
