# 系统设置第二版本地交付

日期：2026-09-09。基线：`eb1ed123ec8e919cad0e78947c9cd9c441dee352`。在第一版隔离工作区继续实现，未提交、推送或部署，未连接生产数据库。

## 实现范围

- 系统设置为企业信息、账号与安全、审计日志、关于版本四个 Tab；管理员旧入口重定向到系统设置。
- 保留现有管理员新增、改名、密码重置、个人改密、启停与存档，读取实际账号；增加角色选择、存档查询和最近登录时间。
- 两种角色：超级管理员、自定义角色。自定义岗位名称必填，可配置模块查看／操作权限；已有管理员原样迁移为超级管理员。
- 权限在后端认证门禁、前端导航、路由及写操作入口共同执行。未列入权限映射的接口对自定义成员默认拒绝。
- 授权与账号管理、登录策略修改、会话强制退出、发布操作仅限超级管理员，防止通过账号管理提升自身权限。停用与角色降级共用企业行锁，保护最后一个有效超级管理员。
- 下拉筛选所需厂商、资源、模型、主体目录通过独立的基础引用接口提供，只包含标识、名称、类型和状态，不返回凭证、余额或后台配置；完整模块权限仍独立校验。
- 登录安全沿用 12～128 位且同时含大小写、数字、特殊字符的密码策略。支持首次改密开关、失败次数及计数窗口、会话时长配置、有效会话列表与强制退出。
- 会话时长缩短会限制既有会话剩余有效期，延长策略不延长旧会话。失败计数沿用当前单进程内存实现，按 IP＋账号分组；服务重启或策略变更会重置计数，不宣称跨实例持久锁定。
- 审计按企业时区支持单日／日期区间、操作人、结果、对象类型、关键词和分页；展示中文动作、操作人及变更详情。旧记录未标注来源时保持“来源未标注”，不倒推历史操作者类型。
- 关于版本保留升级记录和更新说明，删除前端升级详情入口；后台发布记录继续保留。当前版本从运行环境 `APP_VERSION` 读取，未注入时明确显示未提供，不将示例或最近一次部署记录伪装成当前运行版本。
- 不新增集成、通知、数据管理入口；不恢复 Logo 上传或标题下方说明文字。

新增 `0072_admin_roles_security`：管理员角色类型、自定义岗位配置、企业登录策略、会话元数据与审计来源。第一版 `0071` 保持保留；已发布 `0000–0070` 迁移内容未修改。
