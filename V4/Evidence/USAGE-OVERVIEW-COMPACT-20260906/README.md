已通过用户登录的生产浏览器复核本周员工概览：4020 次请求、92 笔未知质量；从同周期/同主体口径下钻，筛选已结算失败请求得到 100 条，抽查第一页 20 条输入/输出/缓存/扣减均为 0。详见 production-observation.json。92 是计量质量数量，100 是失败请求数量，不能直接说两者完全重合。源码已确认原概览缺少最终请求成功态过滤。
