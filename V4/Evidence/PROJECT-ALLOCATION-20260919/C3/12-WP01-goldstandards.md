# WP01 金标算例与不变性范围（冻结）— 候选 C3

## A. 金标（全部测试数据；期望值独立于实现推导）

- **GS-1（C01/M03）** 三段：100 万 A100%、200 万 A60/B30/余、300 万退出 → A 2,200,000 / B 600,000 / 未 3,200,000；员工账 600 万不变；首段 MEMBERSHIP_RULE≠人工指定；边界时刻闭开正确；三级守恒+逐行覆盖。
- **GS-2（C02）** 1 Token A3333/B3333/余3334 → 0.3333/0.3333/0.3334 精确；10^15×6000bps 无溢出。
- **GS-3（C03）** GS-1 池+直接 10 万(A)+人工 20 万(B)：源 630 万；A 230/B 80/未 320；10+20+280+320=630；涉及请求数目标内去重不可跨项目相加。
- **GS-4（C04）** API CNY 100.0000/API USD 20.00/套餐 CNY 50.00 × A6000/B3000/余1000：三桶分别守恒；`package_cost_currency='CNY'` 落库。GS-4b 0.01 尾差确定性（平局按项目键字典序，未分配最后）。GS-4c UNKNOWN 费用→NULL+完整性缺口计数。
- **GS-5（C08/W01-0%）** 资源级余量 100.00 CNY 无 token 行不伪造；**0% 段（P3-3）**：weight_bps=0 显式保存展示，结果 100% 未分配原因 WEIGHT_REMAINDER，不折叠不误标。
- **GS-6（C05/C06）** 跨月开始次月结算→次月批次+当时规则；同请求 3 Attempt（含失败有消耗）同时点匹配、attempt_id 逐行不重不漏。
- **GS-7（W02/W03）** 仅参加未设权重→NO_EFFECTIVE_RULE；规则超参与核算区间→具体冲突段。
- **GS-8（W04/A01）** 并发发布一成一冲突无超配；项目页只提交本项目意图，隐藏规则不被覆盖；企业级入口无 operate→403、跨企业→404（P2-2）。
- **GS-9（H02/H04）** close 冻结 ref（不复制明细）；被引用 run 禁删禁改；重开新规则再 close 只新版本指新 run。
- **GS-10（P2-1）** 预览数字：隐藏 3000、意图 2500 → available 7000、remaining 4500；可见 B 占 2000 时 B 单列、实际可再占 2500。
