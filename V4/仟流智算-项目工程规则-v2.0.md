## 4. 命令、副作用与验证状态

### 4.1 副作用等级

| 等级 | 含义 | 当前未授权 Stage 03 |
| --- | --- | --- |
| `READ_ONLY` | 不写仓库、不启服务、不改数据、不出站 | 允许 |
| `LOCAL_WRITE` | 写缓存、`node_modules`、`dist`、coverage、report 或临时文件 | 禁止，除非进入获授权工作包 |
| `SERVICE` | 启服务、容器、端口、网络或后台进程 | 禁止，除本地原型 Evidence 已单独授权并收口 |
| `DATA_MUTATION` | 迁移、插数、TRUNCATE、业务写入或外部有副作用调用 | 需精确环境与 Owner 授权 |
| `DESTRUCTIVE` | down migration、删卷、销毁、覆盖或难恢复动作 | 默认禁止；必须具备精确目标、备份／恢复、双人职责或专项批准 |

## 6. 数据、隐私、网络与端口

- PostgreSQL 是业务事实源；Redis 只存可重建派生状态。`usage_event / ledger_line / settlement / statement / audit` 的不可变与 append-only 合同不得被测试或修复脚本绕过；
- 开发、测试和 Evidence 使用合成或批准脱敏数据。客户数据不得复制进仓库、个人目录、第三方模型、未经批准对象存储或 `_knowledge_base/`；
- 调用正文固定 `METADATA_ONLY`，不得留存在 DB、Redis、日志、Trace、对象、错误、Fixture 或 Evidence；
- 现有允许出站只有按环境批准的 DeepSeek、智谱、Kimi／Moonshot、Kimi usage、智谱 quota 和企微 `qyapi`；install、audit、镜像拉取、Git fetch 也属于网络。新增域名或对象存储进入 allowlist 前默认拒绝；
- Compose 的 PG、Redis、Control API、Gateway、Web 当前绑定 127.0.0.1；Caddy `80/443` 绑定全接口且现有 `:80` 配置不等于生产 TLS。未做网络评审不得启动 Caddy 或对外暴露端口；
- 本轮“对账与导出”只允许 `Coming Soon`，不得为该占位页新增对象存储、导出 Worker 或下载链。
