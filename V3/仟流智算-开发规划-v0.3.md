## 1. 当前版本主目标

以企业级 Token 管理为底座，让仟流科技先通过一个可管理、可路由、可审计的企业 AI Gateway，把 DeepSeek API、智谱 Coding Plan、Kimi K3 Coding Plan 分配给 10 名员工或项目，完成协议适配、账号池调度、Token 额度、扣减和费用统计。该内部验证是未来服务企业客户及其团队的首个企业样板，不是最终客户边界。

### 1.1 四个不可偏离的产品核心

所有工作包和验收 Evidence 必须至少服务以下一项，或明确属于其横向安全／可靠性约束：

1. **持续生产**；
2. **按量消耗**；
3. **存在峰谷差异**；
4. **必须计量和调度**。

每个核心性质都必须形成“数据输入 → 确定性判断 → 执行动作 → 结果落账 → 可解释查询 → 对账修正”闭环。健康故障切换不能代替经营调度；请求级幂等不能抹掉任何实际 Attempt 的真实消耗。

API、Coding Plan 和账号池资源必须统一产生输入、输出、缓存等 Token 用量事实；厂商扣减、倍率和费用在 Token 事实之上派生，不得反过来覆盖底层用量。

## 2. 一期范围

- 单企业内部先行验证；核心对象保留 `enterprise_id`，不封死企业客户和团队演进；
- 多个同权限管理员；
- 员工／项目统一使用主体；
- 每主体独立 Key，以及模型、IP、有效期、额度和并发限制；
- DeepSeek、智谱、Kimi；
- API 和 Coding Plan；
- Models、OpenAI Chat、Anthropic Messages 一期最低兼容；Responses、Embeddings、count_tokens、SSE／WebSocket 纳入目标协议契约和 PoC；
- Provider／Resource／Unified Model／Model Route；
- API Key／OAuth／套餐账号池、凭证刷新与隔离；
- 能力注册、健康探测、优先级／权重、负载、错误率、TTFT、额度余量、重置时间、边际成本、Session Affinity 和有界故障切换；
- 流式提交边界、取消传播和逐 attempt 路由证据；
- 消耗速度、预计耗尽、下一恢复、覆盖时长和预测可信度；
- 峰谷、成本、额度和剩余周期驱动的受控经营调度与可证明节省；
- 仟流 IDE、WorkBuddy、Claude Code、ZCode；
- 额度、分时价格、扣减倍数和资源池；
- 桌面 Web 七个一级入口；
- 请求级结算汇总、逐 Attempt 不可变账本明细、异常和操作日志；
- 10 人完整自然月验证。

## 3. 非目标

- 手机端；
- 仟流智算 Agent 功能；
- 语音；
- 外部通知；
- 部门和多层预算；
- 多企业管理界面；
- 自动采购；
- 自动同步厂商规则；
- 员工任务选择项目归属；
- 调用正文存储；当前默认零留存，未来企业明确需要时另行立项受控留存能力。
- 跨区域多活、外部租户分级 RBAC；
- 未经 PoC 冻结的扩展协议端点对外启用；其能力契约和测试夹具仍属于本期架构工作。

## 5. Stage 02 里程碑草案

### M1：资源和使用主体可管理

真实闭环：

```text
管理员登录
→ 登记厂商资源
→ 创建员工／项目
→ 生成 Key
→ 分配模型和额度
→ 页面可查
```

完成标准：

- 单企业管理员登录可用；
- 员工／项目统一主体可用；
- Key 明文一次展示、摘要保存、模型／IP／有效期／额度／并发限制、重置和停用可用；
- 三厂商资源和两种模式可登记；
- API Key、OAuth、套餐会话三类凭证状态和生命周期边界可表达；
- Provider、Provider Resource、Unified Model 和 Model Route 可管理；
- 操作日志完整；
- 上游 Secret 不出现在页面和日志。

### M2：Gateway 内核和一个客户端真实调用

真实闭环：

```text
主体 Key
→ Gateway 鉴权
→ 能力校验
→ Model Route
→ DeepSeek
→ 流式返回
→ request／Attempt／usage／ledger lines／settlement
→ Web 可查
```

完成标准：

- `GET /v1/models` 和 OpenAI Chat 兼容协议通过；
- DeepSeek 真实调用通过；
- 稳定 request ID、候选快照和逐 Attempt 证据可查；
- 不支持能力显式报错，不静默丢字段；
- 输入／输出／缓存 Token 用量事实和 API 费用正确；
- 同一计量事实不重复记账，每个真实消耗 Attempt 保留明细；
- 默认正文零留存。

### M3：三类上游和资源池闭环

真实闭环：

```text
员工选择模型
→ Gateway 应用能力、账号池运行状态和多因子评分
→ DeepSeek／智谱／Kimi
→ 套餐优先
→ 提交前同池切换
→ 条件式 API 兜底
```

完成标准：

- 三类上游真实适配通过；
- 多账号并发可用；
- API Key／OAuth／套餐凭证的过期、刷新、隔离和恢复可用；
- 不人为串行化员工调用；
- 健康探测、熔断／冷却和半开恢复可用；
- Session Affinity 命中和资源异常脱离可用；
- 静态优先级／权重、负载、错误率、TTFT、额度余量、重置时间、边际成本和 Affinity 的评分结果可回放、可解释；
- 429、5xx、超时只在流式提交前按预算切换；
- 流式提交后中断不切换、不拼接第二个上游；
- 套餐到 API 的默认关闭和开启路径均通过；
- 上游账号和切换原因可查。

### M4：额度、供给预测、经营调度和分层账本闭环

真实闭环：

```text
资源余额＋Token 用量事实
→ 生成供给预测
→ 请求前命中峰谷／经营策略
→ 执行调度动作
→ 每个 Attempt 计算扣减／费用
→ 汇总结算
→ 更新主体额度
→ 停止或允许超额
→ 预测、决策、账本和异常可查
```

完成标准：

- API 分时价格正确；
- 套餐倍数正确；
- API 和套餐都保留统一 Token 用量事实，扣减与费用分别派生；
- 厂商周期重置正确；
- 并发额度预占不穿透；
- 一个请求只有一个结算汇总，每个真实消耗 Attempt 都有不可覆盖明细；
- 消耗速度、预计耗尽、下一恢复、覆盖时长和可信度可查；
- 峰谷规则在请求前参与判断并执行已发布的受控动作；
- 只有具备反事实证据的实际动作计入调度节省；
- 额度用完默认停止；
- 超额值和比例正确；
- 历史规则版本不被重算。

## 8. 风险

“退出条件”表示停止受影响能力、降级或返回 Planning 的硬阈值，不表示删除风险。

| 风险 | Owner | 影响 | 缓解措施 | 退出条件 |
| --- | --- | --- | --- | --- |
| 第三方客户端协议细节不同 | 佳哥（技术） | 填入 Gateway 后局部功能不可用 | 冻结客户端版本并执行协议契约和真实接入测试 | 最低合同 Models／Chat／Messages 任一无法保真时，停止对应客户端交付，不扩大阻塞 |
| Coding Plan 上游行为变化 | 佳哥（技术） | 用量、限流或工具调用不稳定 | Provider Adapter 隔离、规则版本化 | 上线回归失败时停止对应 Provider 上线 |
| 上游不返回完整 usage | 佳哥（技术） | 计量精度降低 | 适配器估算并标记 `usage_quality` | 无法标记来源或无法对账时禁止该资源参与正式计费 |
| 多人并发穿透额度 | 佳哥（技术） | 主体或资源超额 | 请求前预占、事务结算和恢复任务 | 任一重复结算或不可解释超额出现时停止新调用 |
| 价格和套餐规则变化 | 佳哥（产品／技术） | 账本费用或扣减错误 | 管理员维护版本和生效时间 | 找不到请求时点有效规则时拒绝计费请求，不使用猜测值 |
| 仟流 IDE Windows 未完成 | 佳哥（产品） | 8 名 Windows 员工无法使用第一方客户端 | Windows 使用第三方工具，IDE 先在 2 台 Mac 验证 | M6 前仍无 Windows 版本时从本期客户端签字范围移出，不阻塞 Gateway |
| 内容意外进入日志 | 佳哥（技术） | 员工代码和对话泄露 | 字段白名单、日志脱敏和 canary 扫描 | canary 任一命中立即停止试点流量并清理受影响数据 |
| 未来正文留存被当作日志开关实现 | 佳哥（产品／技术） | 企业敏感数据失控 | 独立安全立项、默认关闭、加密、最小权限和可验证删除 | 未完成独立安全评审时永久保持 `METADATA_ONLY` |
| 协议转换静默丢字段 | 佳哥（技术） | 客户端看似成功但语义错误 | Provider 能力注册、契约测试和显式不支持错误 | 必需字段无法保真时拒绝该能力，不得上线 |
| 多协议和 WebSocket 只写接口不做状态边界 | 佳哥（技术） | 长连接泄漏、跨轮次串账或重复输出 | 连接／轮次分层、租约、提交边界、取消和故障注入测试 | 提交后切换、跨轮串账或资源泄漏任一出现时禁用 WebSocket |
| 多因子调度不可复现 | 佳哥（技术） | 选路结果漂移且无法解释 | 版本化评分、因子快照、稳定 tie-break 和历史回放 | 相同快照回放结果不一致时退回确定性优先级路由 |
| OAuth／套餐凭证刷新拖垮账号池 | 佳哥（技术） | 全池不可用 | 单资源隔离、刷新退避、受控探测和重新授权 | 刷新失败影响健康资源时禁用自动刷新并要求人工重新授权 |
| 流式失败跨上游拼接 | 佳哥（技术） | 输出损坏、工具调用重复和重复计费 | 原子提交边界、提交后禁止切换、故障注入测试 | 任一跨上游拼接出现时停止流式入口 |
| Session Affinity 泄露正文 | 佳哥（技术） | 会话内容可被关联或反推 | 只使用显式会话 ID 的 HMAC／随机 ID，独立密钥和短 TTL | canary 或原始会话 ID 命中持久层／日志时禁用 Affinity |
| 重试成本被最终成功覆盖 | 佳哥（技术） | 真实费用和额度被低估 | 每个真实消耗 Attempt 独立明细，请求级汇总只做聚合 | 任何已消费 Attempt 被覆盖时停止结算入口 |
| 同一计量事实重复到达 | 佳哥（技术） | 费用、额度和审计虚增 | 厂商计量去重键、账本明细唯一约束和幂等结算 | 重复记账率不为 0 时停止新调用并对账 |
| 把健康路由冒充经营调度 | 佳哥（产品） | 产品退化为普通 Gateway | 峰谷、成本、额度、周期进入请求前决策并保存 Evidence | 无法保存调度输入和动作时不展示经营调度能力 |
| 耗尽预测制造伪精确 | 佳哥（产品／技术） | 管理员做出错误采购或调度决策 | 保存方法版本、数据窗口、可信度和不可计算原因 | 数据不足或余额未知时输出不可计算，不输出日期 |
| 调度节省虚报 | 佳哥（产品／技术） | 经营看板失真 | 只使用已发布反事实基线和已执行动作 | 缺任一基线或执行证据时节省记为 `NOT_CALCULABLE` |
| 外部源码许可证或来源不清 | 佳哥（技术） | 商业发布和知识产权风险 | 隔离 PoC、精确 Commit／文件／许可证清单、ADR 后受控复用 | Commit／许可证／义务任一不可证明时禁止代码复用 |
| 过度照搬开源产品 | 佳哥（产品／技术） | 仟流业务模型被参考项目反向绑架 | PRD／TRD 为权威，只学习可验证工程能力 | 外部结构改变仟流产品合同且无 ADR 时退回独立实现 |
| 范围再次膨胀 | 佳哥（产品） | 一期无法收口 | 以 [PRD v0.3 §4](./仟流智算-产品需求文档-v0.3.md#4-阶段边界) 为唯一产品边界 | 新能力无 Planning Change 批准时停止受影响工作 |
