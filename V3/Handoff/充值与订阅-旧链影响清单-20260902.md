## 7. 数据迁移对象

### 7.1 API 期初余额

- 每个现有 API 资源、每种账户币种人工确认 `2026-09-01 00:00:00 Asia/Shanghai` 时点值；
- 候选可参考旧数据，但不得自动把旧快照认定为已确认期初；
- 缺确认资源保持 `MISSING_OPENING_BALANCE`，不得填 0。

### 7.2 9 月 1 日后充值

- 从 `resource_purchase_record` 选择 `API_RECHARGE`；
- 校验资源、币种、金额、业务时间、人民币实付和重复凭证；
- 旧记录缺人民币实付时进入人工缺口清单，不临时换算。

### 7.3 Coding Plan

- 加法迁移后先按已审核旧事实暗创建 `MIGRATED_CARRYOVER` 和 `MIGRATED_PURCHASE` 周期，不产生资金事件；
- 周期校验通过后才允许 Gateway 暗写 `subscription_period_id`；
- 9 月 1 日后新购/续费迁为资金事件与周期；
- 9 月 1 日前已购、切换日仍有效的计划只迁周期元数据，来源为 `MIGRATED_CARRYOVER`，不产生 9 月支出；
- 订单币种、人民币实付或周期缺失时进入缺口清单。

### 7.4 API 使用

- 不复制 `ledger_line`；
- 选择结算时间 >= 切换边界的 API 行；
- 从冻结计价快照/版本回填 `api_cost_currency`；
- 分类回填 `api_cost_status`：已计价、确认未上游零事实、费用未知；
- 以原创建时间回填 `settled_at`；
- 缺失或冲突时失败关闭并列出请求、资源、规则版本和原因。

### 7.5 Coding Plan 使用

- 按结算时间匹配开始日最新的覆盖周期；
- 回填 `subscription_period_id`；
- 无周期或多义冲突进入缺口清单，不猜测。

历史 `ledger_line` 回填是一次性受控迁移例外，只允许补空的币种、费用状态、周期ID和结算时间；Token、费用金额、资源、请求和规则快照必须逐行哈希证明未改变。
