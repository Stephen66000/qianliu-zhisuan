## 背景

POOL-033 已统一接入配置入口，收编了三条旧直写路径：
1. `PATCH /principals/:id/key` 直写 Key 白名单
2. `POST /principals/:id/grants` 直建 Grant
3. `PATCH /grants/:id` 直改 Grant

新入口为 `GET/PUT /principals/:id/access-configuration`（编排端点），在单一事务内完成校验、锁 Key、规则版本化、池 Grant 创建/调整/停用、型号开关、白名单重算与审计。

## 迁移指南

### 旧端点 → 新端点映射

| 旧端点 | 新端点 | 迁移说明 |
|---|---|---|
| `PATCH /principals/:id/key` | `PUT /principals/:id/access-configuration` | Key 白名单改为通过 `enabled_model_ids` 配置 |
| `POST /principals/:id/grants` | `PUT /principals/:id/access-configuration` | Grant 改为通过 `provider_pools` 配置 |
| `PATCH /grants/:id` | `PUT /principals/:id/access-configuration` | Grant 调整改为通过 `provider_pools` 配置 |

### 迁移步骤

1. **备份现有配置**：使用 `GET /principals/:id/access-configuration` 获取当前配置
2. **转换为新格式**：
   - 旧 `allowed_model_ids` → 新 `enabled_model_ids`
   - 旧 `quota_value` → 新 `provider_pools[].quota_value`
   - 旧 `allow_overage` → 新 `provider_pools[].allow_overage`
3. **使用新端点保存**：调用 `PUT /principals/:id/access-configuration`
4. **验证配置**：检查 Key 白名单、池 Grant、额度计数器是否一致

### 兼容性保证

- 旧端点在 Sunset 前继续可用，但响应头会标记 `Sunset: 2026-09-30`
- 旧端点在 Sunset 后返回 410 Gone，错误信息包含迁移指南链接
- 旧端点在 Sunset 后不会立即删除代码，保留 30 天作为回滚窗口
