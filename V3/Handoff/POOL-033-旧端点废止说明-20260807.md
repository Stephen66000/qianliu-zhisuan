# POOL-033 旧端点废止说明

> 创建日期：2026-08-07（Asia/Shanghai）
> 责任人：佳哥
> 关联问题：POOL-033 使用主体接入配置与批量模型授权入口割裂

## 废止原因

POOL-033 已统一接入配置入口，收编了三条旧直写路径。旧端点存在以下问题：

1. **入口割裂**：三条旧直写路径并存，管理员开通同一员工要在两个入口各配一遍
2. **撤权语义不直观**：手工权限与规则权限同时存在时，停用规则后员工仍可能通过手工基线继续调用
3. **额度归集维度错误**：旧端点按型号归集额度，不符合按厂商计费的真实管理意图

## 废止范围

| 旧端点 | 废止时间 | 替代端点 |
|---|---|---|
| `PATCH /principals/:id/key` | 2026-09-30 | `PUT /principals/:id/access-configuration` |
| `POST /principals/:id/grants` | 2026-09-30 | `PUT /principals/:id/access-configuration` |
| `PATCH /grants/:id` | 2026-09-30 | `PUT /principals/:id/access-configuration` |

## 废止行为

### Sunset 前（2026-09-01 ~ 2026-09-30）

- 旧端点继续可用，但响应头添加 `Sunset: 2026-09-30`
- 旧端点在文档中标记为"已废弃"
- 旧端点在管理后台不再推荐使用

### Sunset 后（2026-09-30 起）

- 旧端点返回 410 Gone
- 错误信息包含迁移指南链接
- 旧端点代码保留 30 天作为回滚窗口

### 清理后（2026-10-30 起）

- 旧端点代码删除
- 旧端点文档归档

## 迁移指南

### 旧端点 → 新端点映射

| 旧端点 | 新端点 | 迁移说明 |
|---|---|---|
| `PATCH /principals/:id/key` | `PUT /principals/:id/access-configuration` | Key 白名单改为通过 `enabled_model_ids` 配置 |
| `POST /principals/:id/grants` | `PUT /principals/:id/access-configuration` | Grant 改为通过 `provider_pools` 配置 |
| `PATCH /grants/:id` | `PUT /principals/:id/access-configuration` | Grant 调整改为通过 `provider_pools` 配置 |

### 迁移步骤

1. **备份现有配置**：使用 `GET /principals/:id/access-configuration` 获取当前配置
2. **转换为新格式**：
   - 旧 `allowed_model_ids` → 新 `enabled_model_ids`
   - 旧 `quota_value` → 新 `provider_pools[].quota_value`
   - 旧 `allow_overage` → 新 `provider_pools[].allow_overage`
3. **使用新端点保存**：调用 `PUT /principals/:id/access-configuration`
4. **验证配置**：检查 Key 白名单、池 Grant、额度计数器是否一致

3. 排查问题，修复后重新计划 Sunset
