## 1. 改动清单

### 1.1 核心修复

`employee-model-rule-repository.ts` `catalog()` 方法的 model_route 查询新增一行：

```ts
.where("model_route.enabled", "=", true)   // ← 新增：隐藏未启用 route
```

完整上下文（`employee-model-rule-repository.ts:101-120`）：

```ts
this.db.selectFrom("model_route")
  .innerJoin("unified_model", ...)
  .innerJoin("provider_resource", ...)
  .innerJoin("provider", ...)
  .select([...])
  .where("model_route.enterprise_id", "=", enterpriseId)
  // 隐藏未启用 route（pool033 切型号时停用的旧笼统别名，如 K3/zhipu）；
  // 与 validation 的 ALL 范围语义一致（enabled=false 本就不会进 readyTargets 被发布）。
  // 历史用量仍可在用量账本按 alias 查到，不删除。
  .where("model_route.enabled", "=", true)
  .orderBy("provider.name")
  .orderBy("unified_model.display_name")
  .execute(),
```

- 新增断言：`expect(...models.find(id === disabledRouteModelId)).toBeUndefined()`。
- **原有断言不变**：2 条 enabled=true 的 route 仍期望出现并 ready。
