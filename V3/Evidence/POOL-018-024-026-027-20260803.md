## 实现结果

### POOL-018 重置周期

- 套餐重置周期新增季度、年度，按自然月锚点处理月末和闰年，不使用固定毫秒数。
- 配置、周期账本、经营快照和 Web 回显保持同一枚举语义，历史周期不重算。

### POOL-019 金额精度

- 总金额输入最多两位小数，列表、详情、确认信息和历史快照统一两位展示。
- 空字符串保持空值，不误转为 `0.00`；Token 单价等高精度字段不套用金额格式。

### POOL-020 本月 API 费用

- 只汇总 API 模式资源的已结算调用成本，套餐和 Coding Plan 请求不进入该指标。
- 使用 `Asia/Shanghai` 自然月口径，不混入厂商充值、余额或厂商自定义账期费用。

### POOL-021 调度节省

- Gateway 冻结原候选与实际候选的计价证据，以同一 Token 事实计算反事实成本。
- 支持正、零、负节省；证据缺失时标记不可计算，不伪造金额、不重复累计。
- 请求下钻可解释候选资源、规则版本、Token 依据和计算结果。

### POOL-022 供给预测

- Worker 建立生产预测任务，API 资源按金额、套餐资源按额度计算。
- 同一 Tick 幂等；经营快照变化后生成新预测，不覆盖旧快照。
- 页面区分正常预测、数据不足、速度为零和余额未知。

### POOL-023 资源状态

- 首页从权威厂商资源状态聚合，不再硬编码“全部正常”。
- 多资源按最严重状态汇总，降级、凭证失效、耗尽、限流和不可用均可见。

### POOL-024 Token 总量与员工排行

- 首页资源摘要下新增本月 Token 总量和员工消耗排行。
- 输入、输出、缓存和总量使用 bigint 安全文本；排行只包含员工，排除项目主体，
  并列结果保持稳定。

### POOL-026 升级日志

- 新增独立升级日志表、仓储、Control API、脱敏 Manifest 导入 CLI 和 Web 查询页。
- 支持成功、失败、回滚和有序追加事件，按部署 ID 幂等，不覆盖既有记录。
- 后台“系统日志”包含操作日志／升级日志，可按状态、版本和问题编号筛选。

### POOL-027 模型自动发现

- DeepSeek／Kimi API 通过厂商 List Models 发现；智谱 Coding Plan 使用版本化套餐目录。
- 发现结果按企业和资源保存快照；失败保留上次成功快照并标记状态。
- 确认接入以事务原子创建资源、统一模型和默认禁用路由；完全相同映射幂等，
  同一资源／上游模型可合法映射到多个统一模型别名。
- 普通管理员使用检测、搜索、全选兼容模型、确认接入向导，不再自由输入上游模型。
- 自动接入不修改主体 Key 的 `allowed_model_ids`，也不创建或扩大 Grant。
