### 2.1 `GET /dashboard` —— 首页八项口径聚合（核心）

**口径在后端 DashboardRepository 聚合，前端只展示。** 响应结构：

```typescript
interface DashboardSummary {
  resourceAccountCount: number;        // 1. 资源账号数
  activeEmployeeCount: number;         // 2. 本账期活跃人数
  currentInUseCount: number;           // 3. 当前正在使用人数
  monthlyPackagePayment: string | null;// 4. 本月套餐支付（数据源 gap，当前 null，不伪造）
  monthlyApiCost: string;              // 5. 本月 API 费用（字符串，如 "12.50"）
  monthlyRechargeAmount: string | null;// 6. 本月充值（数据源 gap，当前 null）
  earliestExhaustion: {                // 7. 预计最早耗尽（null = 无可计算预测）
    resourceId: string;
    resourceName: string;
    providerCode: string;
    forecastExhaustAt: string | null;  // ISO 时间
    nextRecoverAt: string | null;
    confidence: string;                // 如 "MEDIUM"
    notCalculableReason: string | null;
  } | null;
  monthlyDispatchSaving: string;       // 8. 本月调度节省（只汇总 saving_calculable=true）
  resourceBreakdown: Array<{           // 资源摘要（按厂商+模式分组）
    providerCode: string;
    providerName: string;
    mode: "API" | "CODING_PLAN";
    accountCount: number;
    totalQuota: string | null;
    usedQuota: string | null;
    monthlyCost: string;
    currentRate24h: string | null;
    forecastExhaustAt: string | null;
    status: string;                    // "HEALTHY"（W20 细化）
  }>;
  overageList: Array<{                 // 超额列表
    principalId: string;
    principalName: string;
    principalType: string;
    provider: string;
    modelAlias: string;
    quotaValue: string;
    usedValue: string;
    overageValue: string;
    overageRatio: string;              // 如 "0.05"
  }>;
}
```

**空状态关键**：新企业无数据时，计数为 0、费用为 `"0"`、`earliestExhaustion: null`、列表为空数组。`monthlyPackagePayment` / `monthlyRechargeAmount` 为 `null`（数据源 gap，**前端不得伪造数字，按 PRD §10.4 空状态展示**）。

#### 仟流青铁律（Web 规范 §3.5，最容易违反）

- ✅ 允许：一个视窗内最重要的 1-2 个数据、AI 执行状态、双色调图标的一个焦点部位
- ❌ 禁止：大块背景、常规正文、所有导航图标、所有按钮、每张卡片边框、持续发光
- ⚠️ 浅色小字青色用 `--ql-accent-text #00787A`，不用 `#00D2D4`（白底对比度 1.88:1 不达标）

#### 仪表盘颜色纪律（仪表盘补充 §3，首页看板必读）

| 内容 | 用色 |
| --- | --- |
| 常态状态（进行中/已完成/待命） | **中性灰标签**，不用蓝绿 |
| 需要人处理/阻塞/异常/失败 | 才用 warning 橙 / danger 红 |
| 装饰/图标/分隔/头像 | 不给状态色，低饱和 |

**原则：颜色是稀缺资源，只分配给"需要用户采取行动"的信号。一个卡片网格中，彩色标签应明显少于灰色标签。**

#### 仪表盘字体三级收敛（仪表盘补充 §4，首页看板必读）

**单一视口内同时出现的视觉层级不超过三级**，且最大的字属于内容而非区块标题：

| 层级 | 内容 | 参数 |
| --- | --- | --- |
| 最重 | 内容主体名（资源名/主体名） | 15/22px, 600, 深色 |
| 次重 | 当前动作/关键一句 | 13/20px, 深灰 |
| 最轻 | 主责/来源/时间/元信息 | 12/18px, 浅灰 |

- 区块标题降为 **16px**（不是页面最大字）
- 统计大数字从 `data-lg 32-48px` **收敛到 24px**——仪表盘里数字是参考，不是主角
- 表格数字用 `font-variant-numeric: tabular-nums`

### 3.4 间距/圆角/阴影（Web 规范 §7）

- **间距**：4px 基准，`4/8/12/16/20/24/32/40/48`
- **圆角**：小标签 6px / 按钮输入 8px / 卡片下拉 12px / 大卡片抽屉 16px / 胶囊 999px
- **阴影**：默认卡片靠背景+边框区分**不用阴影**；浮层（菜单/弹窗/抽屉）才用轻阴影。浅色 `0 12px 32px rgba(15,27,46,0.12)`
- **核心区阴影**（仪表盘补充 §2）：首页若有核心区，`0 4px 16px rgba(15,27,46,0.06)` 轻微浮起

### 3.5 仪表盘结构（仪表盘补充 §1-2，首页看板必读）

#### 区域容器 Zone（Canvas 与 Card 之间新增一级）

```text
Canvas 页面画布（灰 #F4F7FB）
└── Zone 区域容器（白底大卡片，1-4 个）
    └── Card 业务卡片（带边框小卡片）
        └── Control 输入/按钮/标签
```

Zone 参数：白底 `#FFFFFF` / 圆角 16px / 边框 `#E3EAF2`（比内卡浅一档）/ 内边距 16px / 容器间距 20px / 区域标题收进容器内左上角 16px。

#### 核心区规则（一页最多一个核心区）

普通 Zone vs 核心区：

| 手段 | 普通容器 | 核心区 |
| --- | --- | --- |
| 边框 | `#E3EAF2`（浅） | `#D8E1EB`（正常深） |
| 阴影 | 无 | `0 4px 16px rgba(15,27,46,0.06)` |
| 内边距 | 16px | 20px |

首页核心区应是"当下最需要关注的"（如异常/最早耗尽），其余退为次要容器。

### 3.6 组件规范要点（Web 规范 §10）

- **按钮**：同一操作区最多 1 个 Primary；默认高 36-40px，紧凑 32px；加载态保持宽度避免跳动
- **状态标签**：统一"浅色底+深色字"（如 success-soft 底 + success 字），**不用饱和实色底+白字**
- **表格**：数字右对齐 tabular-nums，文字左对齐，操作列固定；大表格提供固定表头/筛选/空状态/加载态；不用大量竖线切"Excel 墙"
- **空状态**（PRD §10.4 + Web 规范）：必须说明"为什么为空、下一步做什么"，不能用空白表格冒充正常页。具体文案见 PRD §10.4 表格（如"新企业没有厂商资源 → 去'厂商资源'登记"）
- **AI 工作状态**：说明正在做什么，不只显示旋转图标（如"正在分析 12 篇…"）

### 3.7 三态（W18 重点：加载/空/错误）

- **加载**：骨架屏（surface-muted 底）或克制 spinner + 文字说明
- **空**：按 PRD §10.4 文案 + 引导动作（去登记/去创建）
- **错误**：danger 色 + 图标 + 文字 + 重试入口

### 3.8 明暗主题（Web 规范 §4）

- 必须支持"跟随系统/浅色/深色"三态，新用户默认"跟随系统"
- `<html data-theme="light|dark">` + `color-scheme`
- 主题切换 160ms 内完成，无闪烁（挂载前初始化脚本）
- **W18 建议**：先把浅色主题做扎实，深色主题 token 已定义（Web 规范 §3.3），可同批或 W20 补

### 3.9 图标（Web 规范 §9）

- 功能图标：Lucide（默认单色线性，16/20/24px，描边 1.75-2px）
- 语义图标：可"仟流蓝描边+浅蓝填充+仟流青单点"双色调，每图标最多一个青点
- ❌ 不用 3D/发光/拟物/廉价 AI 素材

- `pnpm build`
- 禁止 `as any` / `@ts-ignore` / `Record<string,any>`（M1-M4 零使用，M5 保持）

- `feat(m5/w18): <描述>`
- 本地提交，无远程，零上传
