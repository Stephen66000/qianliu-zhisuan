# M5 收口执行清单（宿主机，一页纸）

> 目的：闭合 W18/W19/W20 在本沙箱**已交付代码但未执行**的测试（Docker 集成测试 + Playwright E2E），
> 让 M5 达到可进入双审的状态。每条命令可直接复制。
> **执行环境**：佳哥 macOS 宿主机，需 Docker 运行中。

---

## 0. 一次性环境准备

```bash
cd /Users/mac/Projects/仟流智算

# 1. 修 corepack（W18 起已知缓存故障）
corepack prepare pnpm@11.11.0 --activate
export PATH="$PWD/.corepack-bin:$PATH"
pnpm --version   # 应为 11.11.0

# 2. 启动 Postgres（Docker）
docker run -d --name qianliu-pg -p 5432:5432 \
  -e POSTGRES_PASSWORD=qianliu -e POSTGRES_DB=qianliu postgres:17-alpine

# 3. 数据库连接（写入 .env 或导出）
export DATABASE_URL="postgres://postgres:qianliu@127.0.0.1:5432/qianliu"
```

## 1. 依赖与迁移

```bash
pnpm install --frozen-lockfile
pnpm db:migrate
```

## 2. Docker 集成测试（硬门禁①）

```bash
pnpm -r run test
```

**预期**：包含 `w19-admin-writes`（9 用例）、`w20-diagnostics-alerts`（9 用例）及 database/gateway 既有套件全部通过。
（Testcontainer 会自起 PG 容器，与上面手动启的 PG 不冲突。）

## 3. Playwright E2E（硬门禁②）

```bash
# 种子管理员（幂等；默认 admin / admin123，可用 --password 覆盖）
pnpm --filter @qianliu/control-api seed:admin \
  -- --enterprise "仟流试点企业" --username admin --password admin123

# 安装浏览器
pnpm --filter @qianliu/web exec playwright install chromium

# 跑 E2E（webServer 自动拉起 control-api:8788 + web:5173）
pnpm --filter @qianliu/web test:e2e
```

**预期**：`e2e/wt-web.spec.ts` 全部通过。失败排查：`pnpm --filter @qianliu/web exec playwright show-report`。

## 4. Win11 Chrome 实机回归（硬门禁③，DEP-WINDOWS）

在 Windows 11 机器上克隆/同步本仓库后，重复 §0~§3 的 `test:e2e`。
（M5 DoD 要求 macOS + Win11 Chrome 双浏览器通过。）

## 5. 全部通过后 → 进入 M5 双审

```bash
# 重新生成对象锁
python3 V3/tools/candidate_lock.py generate --paths-file <paths>
```

然后交**独立会话**做 M5 双审（功能 + 代码质量），双审输入：
- `V3/Evidence/M5/W18/`、`V3/Evidence/M5/W19/`、`V3/Evidence/M5/W20/`
- 本清单 §2/§3/§4 的执行结果（测试报告）

## 故障速查

| 症状 | 处理 |
| --- | --- |
| `Cannot find module .../corepack/v1/pnpm/...` | 重跑 §0.1 修 corepack |
| `Could not find a working container runtime` | Docker 未启动：`open -a Docker` |
| E2E `seed-admin` 连接失败 | 确认 `DATABASE_URL` 指向 §0.2 的 PG |
| E2E 登录 401 | 确认 §3 种子管理员已执行且密码一致 |
| `pnpm -r run test` 某包挂 | 单独复跑：`pnpm --filter <pkg> test` 看详情 |
