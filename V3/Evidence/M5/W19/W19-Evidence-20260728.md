## 3. 关键设计决策

1. **并发语义：`updated_at` 乐观锁**，不引入 ETag/版本字段。前端携带读取快照的 `expected_updated_at`，`UPDATE ... WHERE updated_at = <snapshot>` 0 行命中 → 区分 404（不存在）/409（期间被改）。登记于 PC-20260728-07。
2. **幂等**：创建类操作沿用既有"状态守卫"（Key 已有 ACTIVE 返回 409 key_exists）；凭证恢复是状态机迁移（仅隔离态可触发，非隔离态 409），天然幂等；PATCH 更新由乐观锁防止并发写覆盖。TRD §11.2"幂等键"在管理端语义为"重复提交安全"，以上三条满足；网关下游 `idempotency_key` 不动。
3. **凭证安全红线**：恢复可携带 `credential_plaintext` 轮换——明文仅一次接收，路由层立即 `encryptCredential` 加密 + 指纹，密文入库、版本递增；响应只回指纹。canary 测试扫表 0 命中。
4. **恢复语义**：仅隔离态（CREDENTIAL_INVALID/EXHAUSTED/EXPIRED/UNAVAILABLE）可恢复 → DEGRADED 观察态；ACTIVE/DEGRADED 调 recover 返回 409 invalid_state。
