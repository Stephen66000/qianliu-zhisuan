## 执行（PowerShell，逐行）

```powershell
cd C:\path\to\仟流智算          # 换成你拷贝到的实际路径
$env:PATH = "$PWD\.corepack-bin;$env:PATH"
pnpm --version                  # 应 11.11.0

# 依赖（首次会提示 approve-builds；勾 argon2 + esbuild 两个）
pnpm install --frozen-lockfile
pnpm approve-builds             # 空格勾 argon2 / esbuild，回车

# 起专用 Postgres + 环境变量（禁止指向开发/生产库）

$env:DATABASE_URL="postgres://postgres:qianliu@127.0.0.1:55432/qianliu_e2e"
$env:GATEWAY_KEY_PEPPER="m5-e2e-only-pepper"
$env:CREDENTIAL_KEK="ZGV2LW9ubHkta2VrLXJlcGxhY2UtaW4tcGlsb3QAAAA="

# 装浏览器 + 跑 E2E（globalSetup 自动迁移、清库并播种确定性夹具）
pnpm --filter '@qianliu/web' exec playwright install chromium
pnpm --filter '@qianliu/web' test:e2e
```

## 故障速查

| 症状 | 处理 |
| --- | --- |
| `pnpm approve-builds` 无交互 | 已在 `pnpm-workspace.yaml` 声明 argon2/esbuild，可跳过 |
| 5432 被占 | 换 `-p 55433:5432` 并同步改 `DATABASE_URL` 端口 |
| 全局夹具拒绝执行 | 数据库名必须以 `_e2e` 结尾，主机必须是 `localhost` 或 `127.0.0.1` |
| 数据库连不上 | 确认 `qianliu-pg-e2e` 容器在跑：`docker ps` |
| E2E control-api 起不来 | 确认上面 3 个 `KEY_PEPPER/KEK/COOKIE_SECRET` 都 export 了（F-02 缺一个即退） |
| 看 trace | `pnpm --filter '@qianliu/web' exec playwright show-report` |
