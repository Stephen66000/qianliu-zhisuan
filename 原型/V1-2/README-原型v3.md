## v3 核心调整

- 保留七个一级入口，不新增 Gateway 独立一级菜单；Gateway 作为执行引擎贯穿首页、厂商资源、额度规则、用量账本、异常告警和系统设置。
- 「厂商资源」从单张账号表升级为四个对象：Provider、Provider Resource、Unified Model、Model Route。
- 新增统一模型与路由、资源账号、Provider 能力、持续供给四个页内标签。
- 新增账号池硬过滤与多因子评分解释，覆盖优先级、权重、负载、错误率、TTFT、额度、重置、成本和 Affinity。
- 新增 API Key／OAuth／套餐会话凭证状态、独立隔离、冷却和受控恢复。
- 新增目标协议能力矩阵；未启用能力返回明确错误，不静默降级。
- 新增消耗速度、预计耗尽、下一恢复、覆盖时长、预测依据和可信度。
- 新增经营调度策略、等价资源组、调度动作和有证据的节省口径。
- 用量账本保留请求级结算汇总，并展示逐 Attempt 明细、流式提交边界、Session Affinity、评分输入、reason code 和调度证据。

## 原型边界

- 数据为内置模拟数据，操作仅前端即时反馈，不持久化。
- 「原型场景」是走查辅助装置，不是正式产品功能。
- Gateway 地址、Key、凭证指纹、策略版本和预测数字均为示例。
- 目标协议进入统一能力模型，不代表一期全部启用；实际启用顺序仍由 PoC 冻结。
- v3 是产品与交互原型，不代表 PoC、接口契约或真实上游能力已经通过。
