# Change Proposal: 企业微信自建应用 Token 每日长图日报与实时交互查用量

## 1. Why (背景与动机)

仟流智算已完成企业微信自建应用的对接与通讯录人员候选池导入。目前企业员工已逐步通过 AI 员工主体使用大模型（通过 IDE、WorkBuddy 等工具接入 Gateway 调用）。

然而，团队面临两个现实痛点：
1. **管理层与负责人缺乏即时感知的全员用量看板**：管理员希望每天能自动收到一张清晰直观的 Token 消耗长图（汇总全员消耗、活跃人员数、模型分布以及各成员用量排行榜），无需专门登录后台电脑查看；
2. **员工缺乏随时自查消耗的便捷入口**：员工在使用大模型过程中，关心自己今天的用量、本周或上一周的消耗情况。目前没有移动端快捷入口，员工无法自助获悉自己的额度消耗节奏。

为此，本方案旨在基于企业微信自建应用构建两个核心业务闭环：
- **每日 Token 使用情况长图看板定时推送**；
- **企业微信自建应用窗口交互式查用量（Chatbot 实时问答）**。

## 2. 核心架构模型与业务闭环

```text
┌─────────────────────────────────────────────────────────────┐
│                      企业微信自建应用                        │
└──────────────┬───────────────────────────────┬──────────────┘
               │                               │
       【闭环 1：主动查询问答】                 │      【闭环 2：定时日报推送】
  员工发消息: "我今天用了多少token"             │      每日 09:00 自动触发
               │                               │
               ▼                               ▼
┌──────────────────────────────┐ ┌─────────────────────────────┐
│ apps/control-api             │ │ apps/worker                 │
│ - 回调路由: /api/wecom/callback│ │ - 定时任务: 每日数据汇总    │
│ - 企微 AES 验签与消息解密    │ │ - 渲染引擎: SVG -> 高清 PNG │
│ - 意图识别: 今天/昨天/上周等 │ │ - 上传企微临时素材获取 media│
│ - 身份定位: WeComID -> 主体  │ │ - 推送图片及文字摘要给指定人│
│ - 查询用量并排版图文回复     │ │                             │
└──────────────────────────────┘ └─────────────────────────────┘
```

## 3. 改动范围与受影响模块 (Scope of Changes)

1. **加解密套件 (`packages/provider-adapters`)**：
   - 增加企业微信官方加解密工具 `wecom-crypto.ts`（支持 SHA1 签名校验、AES-256-CBC 消息解密与回复加密）。
2. **控制平面回调与智能问答 (`apps/control-api`)**：
   - 增加 `/api/wecom/callback`（GET 响应微信 URL 验签，POST 接收消息）；
   - 增加自然语言时间意图解析器 `intent-parser.ts`；
   - 增加问答业务处理器 `message-handler.ts`（查询个人用量并排版回复）。
3. **Worker 日报长图渲染与推送 (`apps/worker`)**：
   - 扩展 `WecomAppClient`，支持素材上传（`/cgi-bin/media/upload`）与图片发送；
   - 增加 `daily-token-report.ts`（数据指标汇总、现代深色风格 SVG 模板生成、PNG 转换 Buffer）；
   - 支持命令行调试 `worker daily-token-report` 与 scheduler 每日定点调度。
