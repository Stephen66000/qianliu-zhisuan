## 3. 总指挥已定决策（照做，不另行发明）
1. 迁移 0093：`billing_rule` 加列 `source_status varchar(16) NOT NULL DEFAULT 'UNVERIFIED'`，CHECK 约束 ∈('VERIFIED','UNVERIFIED')；提供 down（drop column）。存量行默认 UNVERIFIED。既有 `source` 列（0011，自由文本来源描述）不动。
2. 聚合函数签名（名字可用 loadApiCostEstimation）：
   `loadApiCostEstimation(db, enterpriseId, { start, end, resourceIds? })` →
   `{ scope: {enterpriseId, resourceIds: string[]|null}, period: {start, end}, amounts: Array<{currency, amount}>, completeness: 'KNOWN_COMPLETE'|'KNOWN_PARTIAL'|'ZERO_CONFIRMED', gaps: Array<{reason, count}>, priceBasis: Array<{ruleId, ruleVersion, sourceStatus}>, excludedNoRecordedCost: number }`
3. 聚合语义（只查 `ledger_line`，`resource_mode='API'`；禁止 JOIN 资金表/快照表/候选表）：
   - 已知金额行 = `api_cost IS NOT NULL` 的行（金额用 `effectiveReportedApiCostSql`（`packages/database/src/repositories/usage-cost-disposition-projection.ts`，处置投影权威口径）；按 `api_cost_currency` 分组 SUM，8 位小数字符串；币种 NULL 的已计价行不入桶、计 `CURRENCY_MISSING` 缺口）。
   - 明确零 = `api_cost_status='CONFIRMED_ZERO_NO_UPSTREAM'`（0 贡献、不算缺口）。
   - 处置排除 = `api_cost IS NULL` 且 `effectiveUsageCostDispositionSql` 为真（0 贡献、不算缺口、计入 excludedNoRecordedCost）。
   - 缺口行 = `api_cost IS NULL` 且未处置排除且非 CONFIRMED_ZERO：`NOT_MIGRATED`（api_cost_status='NOT_MIGRATED'）；否则按 usage_quality 分 `USAGE_UNKNOWN`（='UNKNOWN'）/`PRICE_MISSING`（其他，即用量已知缺价格）。
   - completeness：存在任一缺口行 → KNOWN_PARTIAL；无缺口且期间只有 CONFIRMED_ZERO/处置排除（无已计价金额行）→ ZERO_CONFIRMED；否则 KNOWN_COMPLETE。期间无任何 API 行 → KNOWN_COMPLETE + 空 amounts（记录该语义）。
   - gaps 另加信息项 `PRICE_BASIS_UNVERIFIED`（count=由 source_status='UNVERIFIED' 的规则计价的行数，不影响 completeness）。
   - priceBasis = 期间内计价行涉及的 `billing_rule_id`/`rule_version`/该规则现值 source_status（JOIN billing_rule 只为取 source_status，允许）。
   - 金额一律 decimal.js（沿用既有 Money clone 惯例），禁止 float。
4. 期间过滤：候选用 `settled_at >= start AND settled_at < end`（与 `dashboard-home-costs.ts` loadWindowOperatingFinance 一致）。**必须先核实** ledger_line 各状态行 settled_at 是否可能为 NULL（查迁移定义与写入点，file:line 证据）；若有 NULL 场景，停下来在回报中说明，不要自行改口径。
5. BillingRule 类型加 `sourceStatus?: "VERIFIED" | "UNVERIFIED"`（可选，避免破坏既有构造）；gateway billingRuleSnapshot 输出 `sourceStatus`（undefined→'UNVERIFIED'）。规则创建/查询合同：zod 加 `source_status: z.enum(["VERIFIED","UNVERIFIED"]).optional()`，缺省落库 'UNVERIFIED'；响应透出。
