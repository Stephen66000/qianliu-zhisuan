## 1. 概述

本次变更取消 API 内部余额管理（期初、充值、对账、结转、资金就绪门槛），改为按真实用量计算**API费用估算**，官方返回的余额单独展示为**官方账户余额**。动机是让管理员不再为一个参考数字承担每月初的资金维护工作：新建 API 资源不再要求资金初始化即可使用，费用数字直接来自经由仟流的请求计价，官方余额由后台定期同步并支持手动刷新，员工月度额度、Coding Plan 套餐、上游真实耗尽后的隔离与恢复等使用控制全部保留。历史已关账版本和旧资金事实只读留档，不回填、不改写。

项目于 2026-11-02 立项，至 2026-11-05 完成发布候选、生产只读补核及 R1/R2 两轮验收返修。R1 修复四项功能阻断并补齐负向回归、A/B 与恢复演练；R2 根治 X02 时钟问题，完成全量干净复跑、根 build 和证据 SHA 绑定。**R2 终审后 50 条功能矩阵全部 PASS，整体结论为有条件通过（§6.2）**。生产环境未做任何部署，当前生产版本仍为变更前的 4691a/f27cb50（迁移水位 0091），W20-10 与其他发布前置继续阻断发布，详见第 5 章。

### 3.1 WP0：基线与契约（2026-11-02）

目标：在动手前把"代码是什么、生产是什么、契约改哪里"钉死。交付 [baseline.md](work-packages/WP0/baseline.md)（源码基线＝远端 main `ae506fe`（PR #7 合并提交）、迁移水位 0000-0092、0093 起编号）与 [contracts.md](work-packages/WP0/contracts.md)（五份接口合同落到实际路由与字段、切换顺序），以及四份调查笔记：19 个 API 资金写入口逐个判定退役/保留/拆分、3 组数据库触发器、PENDING 准入过滤点、费用读取链路、余额同步三处耦合、测试与 CI 真实/占位脚本清单。本包纯文档，无业务提交（change 文档随 `5b16dd6` 入册），无测试用例。
