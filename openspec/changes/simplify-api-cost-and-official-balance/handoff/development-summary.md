## 1. 概述

本次变更取消 API 内部余额管理（期初、充值、对账、结转、资金就绪门槛），改为按真实用量计算**API费用估算**，官方返回的余额单独展示为**官方账户余额**。动机是让管理员不再为一个参考数字承担每月初的资金维护工作：新建 API 资源不再要求资金初始化即可使用，费用数字直接来自经由仟流的请求计价，官方余额由后台定期同步并支持手动刷新，员工月度额度、Coding Plan 套餐、上游真实耗尽后的隔离与恢复等使用控制全部保留。历史已关账版本和旧资金事实只读留档，不回填、不改写。

项目于 2026-11-02 立项（用户确认业务边界并交付三份规格与计划），至 2026-11-05 完成发布候选与生产只读补核收尾，历时四天。关键数字：**28 笔提交、370 个文件变更（+27217/−2402）、7 个工作包严格串行执行、21 项实施任务全部完成勾选、新增 4 个数据库迁移（0093–0096）、50 条验收场景全部 PASS（42 个规格场景＋8 项集成回归）**，另完成业务走查六步签收与切换/回退两场隔离演练。生产环境未做任何部署，当前生产版本仍为变更前的 4691a/f27cb50（迁移水位 0091），详见第 5 章。
