## 🧭 01 / 场景定位与整体架构

企业微信智能查用量交互（WeCom Chatbot）旨在为企业员工及团队管理者提供**即问即答、零跳转、高时效**的大模型用量自主查询服务。

用户在企业微信客户端进入“仟流智算”自建应用窗口，输入任意自然语言（如*“今天我用了多少token”*、*“上周消耗”*、*“团队本月用量”*），系统在 **5 秒内**自动完成意图提取、身份鉴权、用量事实聚合与排位计算，并以结构化卡片文本回复。

## 🔐 02 / 安全协议与回调网关

### 2.1 微信加密协议标准
- **加解密算法**：AES-256-CBC，填充方式 PKCS#7，Block Size 32 字节；
- **签名算法**：SHA-1(sort([Token, Timestamp, Nonce, Encrypt]))；
- **安全时效**：微信回调要求接口在 5 秒内返回，系统采用异步非阻塞 SQL 聚合，接口平均响应时延控制在 120ms~280ms。

### 2.2 接口路由定义
1. **`GET /api/wecom/callback`（URL 有效性验证）**：
   - 企微管理员后台配置回调 URL 时，微信服务器发起 GET 探测验签；
   - 校验通过后解密 `echostr` 原样输出。
2. **`POST /api/wecom/callback`（消息接收与被动回复）**：
   - 接收员工发来的上行交互消息；
   - 验证消息签名合法性；
   - 调用消息处理器并返回加密的回复 XML。

## 🧠 03 / 自然语言意图识别矩阵

意图解析模块（`intent-parser.ts`）负责从用户文本中提取两大约束维度：**统计周期（Period）**与**查询范围（Scope）**。

### 3.1 统计周期映射规则
| 用户关键词 | 解析周期 (`period`) | 对应时间范围 | Overview 聚合基数 |
| :--- | :--- | :--- | :--- |
| **今天、今日、today、实时** | `TODAY` | 今日 00:00 至当前时间 | `TODAY` (按小时切片) |
| **昨天、昨日、yesterday** | `YESTERDAY` | 昨日 00:00 至昨日 23:59 | `TODAY` (锚定昨日) |
| **本周、这周、这个星期、this week** | `WEEK` | 本周一 00:00 至当前时间 | `WEEK` (按天切片) |
| **上一周、上周、上个星期、last week** | `LAST_WEEK` | 上周一 00:00 至上周日 23:59 | `WEEK` (锚定上周) |
| **本月、这个月、this month** | `MONTH` | 本月 1 日 00:00 至当前时间 | `MONTH` (按天切片) |
| **上月、上个月、last month** | `LAST_MONTH` | 上月 1 日 00:00 至上月末 23:59 | `MONTH` (锚定上月) |

### 3.2 查询范围与权限判定
| 用户输入特征 | 意图范围 (`scope`) | 权限鉴权要求 | 越权保护行为 |
| :--- | :--- | :--- | :--- |
| 包含“全员、团队、全公司、公司、大家、所有人” | `TEAM` | 必须为企业激活管理员 (`admin_user`) | **自动降级为个人数据**，并在头部友好提示：“*（注：您当前为主体员工，已为您展示个人用量数据）*” |
| 包含“我、个人、我的”，或未显式指定范围 | `SELF` | 仅需绑定有效 AI 员工使用主体 (`EMPLOYEE`) | 仅展示该员工本人的用量、模型与团队排位信息 |

## 🏷 04 / Token “万 / 亿”统一换算标准

严格依循仟流视觉全案核心准则：**全系统彻底废除无单位千分位长纯数字（如 `328,500`），统一推行“万”与“亿”自适应进位规则**。

### 4.1 统一进位换算函数（标准实现）
```typescript
export function formatTokenVolume(
  tokens: number | string | bigint,
  options?: { isDailyAvg?: boolean; showTokensWord?: boolean },
): string {
  const n = typeof tokens === "bigint" ? Number(tokens) : typeof tokens === "string" ? Number(tokens) : tokens;
  const isDaily = options?.isDailyAvg ?? false;
  const suffix = options?.showTokensWord ? " Tokens" : "";

  if (!Number.isFinite(n) || n <= 0) {
    const unit = isDaily ? "万 /天" : "万";
    return `0.0 ${unit}${suffix}`;
  }

  // >= 1 亿 (100,000,000) 升格为“亿”
  if (n >= 100_000_000) {
    const val = (n / 100_000_000).toFixed(1);
    const unit = isDaily ? "亿 /天" : "亿";
    return `${val} ${unit}${suffix}`;
  }

  // < 1 亿统一采用“万”
  const val = (n / 10_000).toFixed(1);
  const unit = isDaily ? "万 /天" : "万";
  return `${val} ${unit}${suffix}`;
}
```
