## 🧭 01 / 产品定位与设计哲学

在仟流智算体系中，周报与激励长图卡片不是冰冷的 IT 监控流水账，而是一张**有温度、有陪伴、有定力的高级手账信笺**。

### 1.1 两大场景的鲜明分工
1. **【场景一：员工个人周报信笺】（全员普惠 · 静水流深）**：
   - 面对公司所有使用 AI 的同事，周一早晨 09:00 送达；
   - 承担**人文陪伴、思维启迪、心态定力**的角色，帮助员工开启新一周的智能协同；
   - 拥有大型专属文库（55 条），满足全年中每周不重样。
2. **【场景二：登顶第 1 名流动红旗】（榜首高光 · 领航致敬）**：
   - 面对周中夺得全团队用量第一的同事即时触发；
   - 承担**卓越肯定、榜样树立、领航担当**的角色，致敬团队先锋；
   - 拥有精选高光文库（9 条），凸显视野与格局。
3. **【场景三：超越 50% 员工成长卡】（大白话事实宣告 · 不设金句池）**：
   - 员工跨过中位数（超过半数同事）时，最震撼、最有力量的就是那句纯粹直接的大白话：
     > **`“ 已经超过了 50% 的同事 ”`**
   - 此位置为**核心事实宣告（Proclamation）**，坚决保持固定原版，绝不添加虚头巴脑的哲理句，保持力拔千钧的真实冲击力。

## 📐 02 / 排版几何与字号自适应阶梯

在卡片排版中，金句位于标题下方（$Y = 237$），采用挂标点悬挂引号 `“ ... ”`（琥珀暖金色 `#D97706`）。为兼顾不同长短金句的视觉美感，引入**字号自适应缩放机制**：

| 金句字符长度 | 推荐字号 | X 轴起始位置 | 适用范围与视觉效果 |
| :--- | :---: | :---: | :--- |
| **短句（8 ～ 9 字）** | **`26 px bold`** | `X = 118` | 经典比例，如《功不求疾，但求有恒》，优雅舒展 |
| **中长句（10 ～ 11 字）** | **`24 px bold`** | `X = 118` | 视觉均衡，如《博观而约取，厚积而薄发》，饱满严整 |
| **长句（12 ～ 13 字）** | **`22 px bold`** | `X = 118` | 紧凑呼吸，如《与其等待答案，不如亲手试试》，两端安全留白 |

> [!IMPORTANT]
> **单行硬约束**：金句严格为单行横排，字符总长度**严禁超过 13 个汉字**（含标点符号），避免冲出右侧边界 $X = 445$。

## 💻 05 / 技术实现与调度算法

### 5.1 代码文件落地位点

- **业务调度调用**：`apps/worker/src/reporting/report-jobs.ts` 与 `incentive-jobs.ts`

### 5.2 全员打散与防疲劳算法（Deterministic Hash + Week Seed）
为了保证：
1. **同周内不同员工的金句完全打散**，全公司形成“金句开盲盒”的多元氛围；
2. **同一员工连续数周不重复**，形成长效常态化的陪伴感。

```typescript
export function pickPersonalWeeklyQuote(key: string): string {
  // key 格式: `${userName}:${weekLabel}`，如 "李佳:2026-W37"
  let hash = 0;
  for (let i = 0; i < key.length; i++) {
    hash = (hash << 5) - hash + key.charCodeAt(i);
    hash |= 0;
  }
  const idx = Math.abs(hash) % PERSONAL_WEEKLY_QUOTES.length;
  return PERSONAL_WEEKLY_QUOTES[idx] ?? PERSONAL_WEEKLY_QUOTES[0];
}
```
