## 🧭 01 / 产品定位与设计哲学

在仟流智算体系中，周报与激励长图卡片不是冰冷的 IT 监控流水账，而是一张**有温度、有陪伴、有定力的高级手账信笺**。

### 1.1 两大场景的鲜明分工
1. **【场景一：员工个人周报信笺】（全员普惠 · 静水流深）**：
   - 面对公司所有使用 AI 的同事，周一早晨 09:00 送达；
   - 承担**人文陪伴、思维启迪、心态定力**的角色，帮助员工开启新一周的智能协同；
   - 拥有大型专属文库（55 条），满足全年中每周不重样。
2. **【场景二：登顶第 1 名流动红旗】（榜首高光 · 领航致敬）**：
   - 面对周中夺得全团队用量第一的同事即时触发；
   - 承担**卓越肯定、榜样树立、领航担当**的角色，致敬团队先锋；
   - 拥有精选高光文库（38 条），凸显视野与格局。
3. **【场景三：超越 50% 员工成长卡】（大白话事实宣告 · 不设金句池）**：
   - 员工跨过中位数（超过半数同事）时，最震撼、最有力量的就是那句纯粹直接的大白话：
     > **`“ 已经超过了 50% 的同事 ”`**
   - 此位置为**核心事实宣告（Proclamation）**，坚决保持固定原版，绝不添加虚头巴脑的哲理句，保持力拔千钧的真实冲击力。

## 📐 02 / 排版几何与字号自适应阶梯

在卡片排版中，金句位于标题下方（$Y = 237$），采用挂标点悬挂引号 `“ ... ”`（琥珀暖金色 `#D97706`）。为兼顾不同长短金句的视觉美感，引入**字号自适应缩放机制**：

| 金句字符长度 | 推荐字号 | X 轴起始位置 | 适用范围与视觉效果 |
| :--- | :---: | :---: | :--- |
| **短句（8 ～ 9 字）** | **`26 px bold`** | `X = 118` | 经典比例，如《功不求疾，但求有恒》、《优秀是卓越的大敌》，优雅舒展 |
| **中长句（10 ～ 11 字）** | **`24 px bold`** | `X = 118` | 视觉均衡，如《博观而约取，厚积而薄发》、《会当凌绝顶，一览众山小》，饱满严整 |
| **长句（12 ～ 13 字）** | **`22 px bold`** | `X = 118` | 紧凑呼吸，如《独行快，众行远；引领者无畏》，两端安全留白 |
| **特长句（14 字）** | **`20 px bold`** | `X = 118` | 沉稳端庄，如《知者不惑，仁者不忧，勇者不惧》，严守右侧边距 |

> [!IMPORTANT]
> **单行硬约束**：金句严格为单行横排，字符总长度**严禁超过 14 个汉字**（含标点符号），确保绝不冲出右侧安全边界 $X = 445$。

## 💻 05 / 技术实现与调度算法

### 5.1 代码文件落地位点
- **文库常数与选择器**：`apps/worker/src/reporting/quote-library.ts`
- **业务调度调用**：`apps/worker/src/reporting/report-jobs.ts` 与 `incentive-jobs.ts`

### 5.2 全年/多次登顶「绝对零重复」打散调度算法（Fisher-Yates Permutation）
为了严格满足：
1. **场景一（个人周报）：同一员工在全年 52 ~ 55 周内领取的金句绝对 100% 零重复**；
2. **场景一（个人周报）：同一周内不同员工的金句彻底打散不撞车**；
3. **场景二（登顶第 1 名）：同一员工连续多次登顶（如本周第一、下周又是第一），金句绝对 100% 零重复**；
4. **场景二（登顶第 1 名）：轮转完全部 38 条高光金句前绝不出现任何重复**。

系统摒弃了存在碰撞缺陷的简单模哈希，升级为**“确定性专属全排列（Fisher-Yates Shuffle）”**算法：
- **个人周报**：基于 `personal:${userName}` 种子的独立全排列，按自然周数（$1 \sim 53$）顺序寻址映射。数学上严格构成双射，**全年 52 周内 0 碰撞、0 重复**；
- **登顶红旗**：基于 `top1:${userName}` 种子的独立全排列，按累计登顶次数（`winCount = 0, 1, 2...`）顺序寻址映射。无论员工连续几周登顶，**每次必定轮转下一句全新高光金句，38 次登顶内 0 碰撞、0 重复**。
