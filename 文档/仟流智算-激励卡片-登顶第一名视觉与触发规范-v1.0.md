## 🎯 01 / 产品定位与激励哲学

### 1.1 从“周底事后通知”到“周中动态夺旗”
在团队协同中，若仅在每周一公布最终周报，存在时效性严重滞后、周中高光时刻被掩盖的问题（例如张三周三努力登顶，周五被李四反超，张三的付出得不到即时反馈）。
本卡片引入**“流动红旗”动态竞争机制**：
- **即时肯定**：员工在周中反超登顶的瞬间，系统即时送达一张专属的高级极简信笺荣誉大图；
- **红旗轮流转**：鼓励团队内人人争当第一，激发健康的 AI 工具使用竞技氛围；
- **克制防扰**：通过严密的冷启动与频控规则，杜绝频繁反超刷屏。

## ⚙️ 02 / 核心触发算法与业务规则（防刷与频控）

| 规则维度 | 约束标准 | 业务设计初衷 |
| :--- | :--- | :--- |
| **1. 蓄水沉淀期** | **周一、周二静默，一律不发** | 刚开周用量基数过小，缺乏统计学说服力，必须蓄水 2 天以上。 |
| **2. 颁奖开放窗口** | **周三 00:00 至 周日 23:59** | 团队进入工作高频期与冲刺期，触发最有含金量。 |
| **3. 全团队每日限额** | **全公司每天最多只发 1 张** | 每天全团队只产生一个“当日焦点”，杜绝企业微信信息过载。 |
| **4. 员工每周限额** | **每人每周最多领 1 次** | 本周登顶即锁定周度荣誉认证；若后续被超再反超，不再重复发，**把发光机会留给尚未登顶的同事**。 |
| **5. 触发判定条件** | **当前排第 1 + 本周未领过 + 当日团队未发过** | 三重条件同时满足，毫秒级触发渲染与发送流程。 |
| **6. 最终大盘定格** | **次周一 09:00 全员周报出炉** | 尘埃落定，在大盘长图上正式公布全周最终总冠军。 |

## 💻 05 / 后端判定与推送实现逻辑 (`apps/worker`)

```typescript
export async function checkAndDispatchTop1Milestone(currentWeek: string, today: string) {
  // 1. 周一、周二静默期不发
  const dayOfWeek = new Date().getDay(); // 0 是周日, 1-6 是周一到周六
  if (dayOfWeek === 1 || dayOfWeek === 2) {
    return; // 静默
  }

  // 2. 检查当天是否已经发放过流动红旗
  const todayIssued = await redis.get(`milestone:top1:issued:${today}`);
  if (todayIssued) {
    return; // 全团队今日配额已用完
  }

  // 3. 计算本周截至当前时刻的 Token 用量榜首
  const [topUser] = await getWeeklyRankings(currentWeek);
  if (!topUser) return;

  // 4. 检查该榜首员工本周是否已经领过该卡片
  const userAwardedThisWeek = await redis.sismember(`milestone:top1:users:${currentWeek}`, topUser.userId);
  if (userAwardedThisWeek) {
    return; // 该员工本周已领过，不重复发放
  }

  // 5. 命中发放条件：渲染 SVG 并转 PNG
  const svg = buildTop1MilestoneSvg({
    userName: topUser.userName,
    metrics: [
      { label: '全员用量排位', value: '第 1 名', sub: '全团队榜首 · 领跑全员', isGold: true },
      { label: '周消耗 Token 总量', value: (topUser.totalTokens / 10000).toFixed(1), unit: '万' },
      { label: '团队消耗贡献占比', value: `${topUser.pct}%`, sub: '超越全员 99% 同事' },
      { label: '主力协同模型', value: topUser.topModelName, sub: '高频深度推理与代码' }
    ]
  });

  const pngBuffer = new Resvg(svg, { fitTo: { mode: 'zoom', value: 2 } }).render().asPng();

  // 6. 上传企微临时素材并私信下发
  const mediaId = await wecomClient.uploadMedia('image', pngBuffer);
  await wecomClient.sendImageMessage(topUser.wecomUserId, mediaId);
  await wecomClient.sendTextMessage(topUser.wecomUserId, 
    `🏆 恭喜 ${topUser.userName}！您已登顶本周全员 AI 协同榜首！\n本周累计消耗 ${(topUser.totalTokens / 10000).toFixed(1)} 万 Tokens，专属流动红旗荣誉信笺已送达，点击查看！`
  );

  // 7. 写入频控缓存
  await redis.set(`milestone:top1:issued:${today}`, 'true', 'EX', 86400);
  await redis.sadd(`milestone:top1:users:${currentWeek}`, topUser.userId);
}
```
