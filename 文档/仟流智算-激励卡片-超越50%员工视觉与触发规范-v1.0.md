# 仟流智算 · 激励卡片（超越 50% 员工）视觉与触发规范

**—— 企业微信 AI 协同「月度成长进阶 · 超越 50%」荣誉推送标准**

> **版本**：v1.0（正式定稿版）  
> **状态**：研发与设计基线  
> **发布日期**：2026-09-12  
> **上位规范**：《仟流视觉法则 1.2》、《仟流智算 · 个人周报小结视觉与格式规范 v1.0》  
> **适用场景**：自然月内，当某位员工在自然月内的累计 Token 用量首次跨过全员中位数（超过 50% 同事）时，通过企业微信自建应用私信即时送达。

## 🎯 01 / 产品定位与设计哲学

### 1.1 大白话沟通与普惠型激励
在企业大模型落地过程中，第一名通常仅有 1 人。绝大多数认真使用 AI 辅助日常工作的业务员工很难登顶。
本卡片专为**“普惠中坚力量”**设计：
- **直击人心的口语化表达**：摒弃“超越中位数”等冷冰冰的统计学词汇，直接采用大白话**「李四 9月份使用 Token 数量」**与**「“ 已经超过了 50% 的同事 ”」**；
- **纯正的智算网关指标**：彻底剥离与企微登录考勤相关的天数指标，纯粹聚焦于**表现、月累消耗总量、累计请求、主力模型**四大核心硬核维度；
- **成长里程碑**：只要跑赢一半同事就给予庄重而温暖的认可，极大激发中间梯队员工的学习与使用积极性。

## ⚙️ 02 / 核心触发算法与业务规则

| 规则维度 | 约束标准 | 业务设计初衷 |
| :--- | :--- | :--- |
| **1. 统计周期** | **自然月（当月 1 日 00:00 至月末 23:59）** | 月度成长视角，给员工充足的时间进行用量积累。 |
| **2. 触发时机** | **当月用量首次跨越全员中位数门槛** | 实时监听用量累积，首次达标毫秒级触发。 |
| **3. 员工月度限额** | **每人每月最多触发 1 次** | 达标即永久记录当月里程碑；后续即便因他人调用被追回，**卡片绝不撤回**，尊重并定格其高光突破时刻。 |
| **4. 触达渠道** | **企业微信自建应用私聊即时下发** | 属于个人的成长喜悦，通过私聊送达，低调温暖。 |

## 💻 05 / 后端判定与触发逻辑 (`apps/worker`)

```typescript
export async function checkAndDispatchOver50Milestone(userId: string, currentMonth: string) {
  // 1. 检查该员工本月是否已经领过该卡片
  const alreadyAwarded = await redis.sismember(`milestone:over50:users:${currentMonth}`, userId);
  if (alreadyAwarded) {
    return; // 本月已领过，不重复发放
  }

  // 2. 获取全团队当月用量中位数 (Median)
  const medianTokens = await getTeamMonthlyMedianTokens(currentMonth);
  if (medianTokens <= 0) return;

  // 3. 获取该员工当月累计用量
  const userMonthStats = await getUserMonthlyStats(userId, currentMonth);
  
  // 4. 判定是否突破中位数（超过 50% 同事）
  if (userMonthStats.totalTokens > medianTokens) {
    // 命中发放条件：生成 SVG 并渲染 PNG
    const svg = buildOver50MilestoneSvg({
      userName: userMonthStats.userName,
      titleText: `${currentMonth.split('-')[1]}月份使用 Token 数量`,
      quote: '已经超过了 50% 的同事',
      metrics: [
        { label: '表现', value: '领跑半数成员', sub: '位列团队前 50%' },
        { label: '月累消耗总量', value: (userMonthStats.totalTokens / 10000).toFixed(1), unit: '万' },
        { label: '累计请求', value: userMonthStats.totalRequests.toLocaleString(), unit: '次' },
        { label: '主力模型', value: userMonthStats.topModelName, sub: '深度推理与综合协作' }
      ]
    });

    const pngBuffer = new Resvg(svg, { fitTo: { mode: 'zoom', value: 2 } }).render().asPng();

    // 5. 上传企微临时素材并私信下发
    const mediaId = await wecomClient.uploadMedia('image', pngBuffer);
    await wecomClient.sendImageMessage(userMonthStats.wecomUserId, mediaId);
    await wecomClient.sendTextMessage(userMonthStats.wecomUserId, 
      `🎉 恭喜 ${userMonthStats.userName}！您本月的 Token 消耗已经超过了 50% 的同事！\n月累计消耗 ${(userMonthStats.totalTokens / 10000).toFixed(1)} 万 Tokens，专属进阶成长信笺已送达，快来看看吧！`
    );

    // 6. 记录本月发放名单
    await redis.sadd(`milestone:over50:users:${currentMonth}`, userId);
  }
}
```
