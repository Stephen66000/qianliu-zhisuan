# 仟流智算 2.0 外部信号

- 收集时间：2026-08-08（Asia/Shanghai）
- 用途：校验现有 PRD／TRD 二期规划的外部趋势，不新增或改变已冻结范围

## 事实

1. Microsoft 于 2026 年 4 月将 Entra Agent ID 平台转为 GA，并把 Agent 365 定位为 Agent 的统一目录与控制平面；Agent ID 负责身份、授权和治理。
2. Microsoft 的 Agent 身份治理要求为 Agent 建立独立身份、生命周期、访问权限和人类 Sponsor，并支持条件访问与审计。
3. NIST 2026 年 AI Agent 安全调研总结指出，Agent 的新型安全风险已成为企业采用障碍；传统安全原则仍适用，但需要针对 Agent 行为扩展。

## 与现有规划的关系

- 上述信号只用于佐证 PRD §4.2 已规划的“仟流智算 Agent”和企业身份／RBAC方向。
- 按 TRD §2.2，仟流智算 Agent 仍应通过公开管理 API 工作，不进入 Gateway 热路径。
- 2.0 主线仍以开发规划 M9“企业团队产品化”为准；本调研不主张新增独立 Agent 治理产品线。
